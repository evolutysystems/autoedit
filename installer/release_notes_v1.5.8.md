## Stretheus v1.5.8 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

> 今回の中心は **DaVinci Resolve への書き出し**の修正です。
> Stretheus 単体で動画を書き出す場合の内容・画質・書式はこれまでと変わりません。

### 修正（アーカイブ切り抜きを Resolve に取り込むと、絵が最大 2 秒ずれました）

アーカイブ（Twitch VOD）から切り抜いた素材を Resolve へ出すと、**カット位置が少し後ろの絵**を
指してしまうことがありました。字幕も同じだけずれるため、全体が「少し遅れた」状態になります。

原因は素材の切り出し方です。切り抜きは再エンコードせずストリームコピーで作るため、
素材の先頭は指定した位置ではなく**その手前のキーフレーム**から始まります
（Twitch VOD では最大 1 GOP ≒ 約 2 秒）。これまでは指定した位置をそのまま足し戻していたため、
その差がまるごとずれになっていました。

v1.5.8 では**実際の切り出し位置を測ってから足し戻す**ようにしました。測定は ffprobe で
素材の先頭パケットを読む方式で、使えない環境ではキーフレーム位置で近似し、どちらも
失敗した場合も従来どおりの値で処理を続けます（**出力が止まることはありません**）。

縦動画プロジェクト（元 VOD への素材張り替え）も同じ計算を共有するよう整理したので、
Resolve 出力と縦プロジェクトでずれ方が違う、ということもなくなります。

### 修正（Resolve が素材を別のフレームレートとして扱い、尺がずれました）

書き出す FCPXML の中で、**素材の寸法とフレームレートに「出力設定の値」を書いていました**。
たとえば 1280x720 / 30fps の VOD を 1920x1080 / 60fps と宣言していたため、Resolve が
取り込み時に素材を 60fps のものとしてコンフォームし、尺や位置がずれていました。

v1.5.8 では**素材自身の実寸と実フレームレート**を測って宣言します。測れなかった場合のみ
従来どおり出力諸元で代用します。

### 修正（字幕の時刻が素材のフレーム境界に合っていませんでした）

字幕の開始・終了を、**その素材のフレーム境界**へ量子化してから書き出すようにしました。
29.97 / 23.976 のような実フレームレートの素材でも、`1001/30000s` 形式でそのまま書けます
（v1.5.7 で入れた実フレームレート対応を、素材側の宣言にも適用した形です）。

### 修正（同時に出した SRT を取り込めないことがありました）

字幕を複数トラック（本文＋コメント）で使っていると、SRT の中で**時刻が逆行**していました。
SRT は 1 本のトラックを時刻の昇順に並べたものでなければならないため、Resolve や他の字幕
ツールが取り込みに失敗したり、表示位置を取り違えることがありました。

- 書き出し時に**必ず時刻の昇順へ並べ替える**ようにしました。
- テロップ整形の丸めで生じる**1 フレーム未満の重なり**は、後ろの開始時刻へ詰めて解消します。
- それ以上の重なり（別トラックの同時表示）は、SRT では 1 本しか表現できないため時刻はそのまま
  残し、件数をログに 1 回だけ記録します（**黙って字幕を落とすことはありません**）。

### 動作要件

- Windows 11 / 64bit。音声認識とぼかしの解析は CPU で行います（CUDA は同梱していません）。
  初回は Whisper モデルを自動でダウンロードするため、ネット接続が必要です。
- FFmpeg/ffprobe・twitch-dl・ぼかし用モデル（YOLOX-Tiny）・VAD モデル（Silero VAD）は同梱済みです。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。新しいキーは起動時に自動で書き足されます。
- 保存済みプロジェクト（`.timeline.json`）は v1.5.7 のものをそのまま開けます。書式は変えていません。
- Stretheus 単体での出力・編集・アーカイブ取得・ぼかし・縦動画・ポイント・ログインの各機能は変更していません。
- 全テスト 1,330 件が通ることを確認しています。

### 確認方法（ダウンロードしたファイルが壊れていないか）

インストーラーは、取得した本体 zip の **SHA-256 を自動で検証**します。
検証に失敗した場合はインストールを中止します。

`StretheusSetup.exe` の SHA-256 は次の値です。気になる場合は照合してください。

```
DEA9F3E54BFB1D91B095B3A7E38728FB30347B5D422505ED641E58B70310BE2F
```

```powershell
(Get-FileHash .\StretheusSetup.exe -Algorithm SHA256).Hash
```
