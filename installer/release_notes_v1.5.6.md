## Stretheus v1.5.6 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

> 今回の変更は **Timeline 編集画面のプレビュー**だけです。
> 出力される動画の内容・画質・書式はこれまでと変わりません。

### 改善（プレビューが「出力された動画」とほぼ同じ絵になりました）

これまで編集画面のプレビューは、**出力とは別の方法で描いた近似表示**でした。
そのため、見えているものと出力結果が食い違っていました。

| これまで | v1.5.6 |
|---|---|
| 縦動画の**背景ぼかしが出ない**（左右が黒いまま） | 出力と同じぼかしが出ます |
| **透かし**が出ない（入るのか分からない） | 入る場合はプレビューにも出ます |
| 字幕の**縁取り・影・行間**が出力と違う | 出力と同じ ASS で焼いた絵が出ます |
| 無音カットのつなぎ目の**フェードが出ない** | 出力と同じフェードが出ます |
| コメントのアイコンや背景の位置が微妙にずれる | 出力と同じ位置に出ます |

仕組みを変えました。**編集した内容を当てた動画を裏で先に作り、それを再生します。**
出力のときと同じ経路（切り抜き → 背景ぼかし → 字幕 → コメントアイコン → 透かし）を
通るため、「プレビューで見えたもの」と「出力されたもの」が同じになります。

### 改善（プレビューの再生が滑らかになりました）

- これまでは**再生しながら 1 コマずつその場で合成**していたため、重い編集内容では
  コマが飛び、秒 15 コマで頭打ちでした。v1.5.6 は作り置きした動画を再生するだけなので、
  編集内容の重さに関係なく滑らかに動きます。音と映像のずれも起きにくくなります。
- **ルーラーの下に細いバー**が出ます。**どこまで用意できたか**を示すもので、
  点滅している部分は今まさに作っているところです。
- まだ用意できていないところを再生・表示したときは、これまでと同じ近似表示を
  下書きとして出し、画面上部に **「プレビューを準備中… (表示は近似です)」** と出します。
  **近似を見ているのか、出力と同じ絵を見ているのかが必ず分かります。**
- 編集すると、**変わったところだけ**作り直します。元に戻す（Ctrl+Z）と、
  作り置きがそのまま使えるため待ち時間がありません。

### 改善（「高精度プレビュー」が本当に出力どおりになりました）

停止中に使える「高精度プレビュー」は、**切り抜きと透かしを通していませんでした**
（縦動画で使うと横のままの絵が出ていました）。原寸・本番設定で描き直すように直し、
ボタンの説明も「現在のフレームを原寸・本番設定で描き直して表示します
(切り抜き・ぼかし・透かしも反映します)」に変えました。

### 既知の制限

- **ぼかし（追いかけ）は、これまでどおり停止中の表示だけです。** 再生中にぼかしを出すには
  再生する範囲を先に解析する必要があり、今回は入れていません。
- プレビューの準備は**編集中の裏側で少しずつ**進みます。長い動画で大きく編集した直後や、
  他の作業で PC が混んでいるときは、近似表示のまま少し待つことがあります。
- 作り置きは一時フォルダに置き、**編集画面を閉じたときに削除**します。残りません。
- 何らかの理由で準備が繰り返し失敗した場合は、**自動的に従来の近似表示へ戻します**
  （画面にその旨が出ます）。編集作業が止まることはありません。

### 設定（動きを変えたい場合）

`{インストール先}\_internal\src\settings\setting.json` の
`timeline` → `preview` → `proxy` で調整できます。通常は変更不要です。

| 項目 | 既定 | 説明 |
|---|---|---|
| `mode` | `"tile"` | `"off"` にすると**従来の近似表示だけ**に戻ります |
| `scale` | `0.5` | プレビューの大きさの比。`0.25` にすると準備が速くなります（絵は粗くなります） |
| `tile_sec` | `4.0` | 1 回に作る長さ（秒）。短くすると作り直しが速くなります |
| `lookahead_tiles` | `3` | 再生位置より何回ぶん先まで作っておくか |
| `coverage_bar` | `true` | ルーラー下のバーを出すか |
| `draft_overlay` | `true` | 未準備の区間で近似表示を下書きとして出すか |

### 動作要件

- Windows 11 / 64bit。音声認識とぼかしの解析は CPU で行います（CUDA は同梱していません）。
  初回は Whisper モデルを自動でダウンロードするため、ネット接続が必要です。
- FFmpeg/ffprobe・twitch-dl・ぼかし用モデル（YOLOX-Tiny）・VAD モデル（Silero VAD）は同梱済みです。
- プレビューの準備にも同梱の FFmpeg を使います。追加で入れるものはありません。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。今回追加した
  `timeline.preview.proxy` は**起動時に自動で書き足されます**。
- 保存済みプロジェクト（`.timeline.json`）は v1.5.5 のものをそのまま開けます。書式は変えていません。
- 近似表示のときのコマ更新上限（`timeline.preview.play_fps`）の**既定**を 15 → 30 へ上げました。
  更新インストールでは既存の値がそのまま残ります（従来どおりの動きです）。
- 出力・編集・アーカイブ取得・ぼかし・縦動画・ポイント・ログインの各機能は変更していません。
- 全テスト 1,199 件が通ることを確認しています。

### 確認方法（ダウンロードしたファイルが壊れていないか）

インストーラーは、取得した本体 zip の **SHA-256 を自動で検証**します。
検証に失敗した場合はインストールを中止します。

`StretheusSetup.exe` の SHA-256 は次の値です。気になる場合は照合してください。

```

```

```powershell
(Get-FileHash .\StretheusSetup.exe -Algorithm SHA256).Hash
```
