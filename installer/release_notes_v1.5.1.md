## Stretheus v1.5.1 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 新機能（縦動画プロジェクトの作成）

- **横動画から、YouTube Shorts 用の縦動画プロジェクトを作れるようになりました**。
  - Timeline 画面でクリップを選び、右クリックの「縦動画プロジェクトを作成...」から開きます。
  - 切り抜き方は 2 つです。
    - **全体** … 枠 1 つ。切り抜いた絵を縦キャンバスへ置き、余った上下はソースをぼかした背景で埋めます。
    - **分割** … 枠 2 つ。上下に積んで縦キャンバス (1080x1920) をぴったり埋めます。
  - 枠はマウスで移動・拡大縮小でき、右側に縦の仕上がりが出ます。
  - 「作成」で、選んだクリップだけを詰めた縦のプロジェクトを保存します。クリップ間の空白は詰めます。
  - 保存したプロジェクトは「クリップ用」タブの「続きから」でそのまま開けます。
  - **切り抜いた動画ファイルは作りません**。切り抜きの指定だけをプロジェクトが覚え、書き出しのときに切り抜きます。
  - 既存の横プロジェクトの出力は 1 バイトも変わりません。
  - オーバーレイ素材 (V2 以降) は引き継ぎません（縦へ置き直す規則が決まらないため。作成時に知らせます）。
  - アーカイブ切り抜き用の Timeline からは作れません（参照している素材が実行の終わりに消えるため）。

### 変更（ぼかしを「囲む → 追う → コマ送りで直す」に作り直しました）

- **何もしなければ、ぼかしは 1 フレームも掛かりません**。クリップを選んで「ぼかし...」を開き、囲んだ場所だけが対象になります。
  - 画面を開いた瞬間に動画全体を解析することはなくなりました。
- **キャンバスをドラッグで囲むだけで指定できます**（「操作」の選び分けは無くなりました）。
  - 1 件目の囲みで「指定した場所をどうしますか？ **ボカす** / **ボカさない**」を聞きます。
  - 「ボカす」… 囲んだ場所がぼけます。
  - 「ボカさない」… **画面全体がぼけ、囲んだ場所だけが素で見えます**。以後は画面のラジオで切り替えて増やせます。
- **囲んだ場所は自動で追いかけます**。ずれたら直せます。
  - ← / → でコマ送り（Shift で 10 コマ、Home / End でクリップの端）。
  - 枠の内側をドラッグで移動、8 個のハンドルで拡大縮小。**動かした時刻にキーフレームが打たれ、そこから追い直します**。
  - キーフレームは必ずその位置・大きさを通ります。
- **指定はそのクリップの中だけに効きます**（「この場面」「この素材全体」は無くなりました）。
- 塗る形は四角 / 角丸 / 楕円から選べます（設定 → ぼかし）。
- **人物の自動検出にまつわる機能は無くなりました**。
  - 人物の枠の一覧・見本画像、人物の名前と割り当て、人物同定 (ReID)、身体の輪郭 (MobileSAM)、主役・統合・分割が対象です。
  - 誰をぼかすかは、囲んで決める形に統一しました。検出モデル (YOLOX-Tiny) は「囲んだ枠を追う助け」として裏で使います。
  - 同梱モデルが 2 つ減り、**ダウンロードの容量が約 43MB 減りました**。

### 新機能（ポイントと透かし）

- **ログインすると、メイン画面の右上に残高と次回リセット日が出ます**。「アカウント」タブでも確認できます。
- **残高が足りないまま出力すると確認ダイアログが出て、続行すると透かしが入ります**。
  - 動画出力・クリップ出力・DaVinci Resolve 書き出しのいずれにも入ります（イントロカードと OP/ED には入りません）。
- **未ログインのままなら、これまでと何も変わりません**。ポイントを消費せず、透かしも入りません。

### 修正

- **Timeline の「セクション追加...」の不具合 3 件を修正しました**。
  - 保存して開き直すと「このプロジェクトが使っている動画素材が元の場所にありません。」が出る（セクションを統合すると、畳まれた側の素材の復元情報が捨てられていました）。開くときに自動で修復します。
  - セクション追加した動画に、再度参照できる動画と参照できない動画があった（同じ原因です）。
  - まだ Timeline 上で使っていない時間なのに「使用している」と断られる（実際に Timeline に載っている区間だけを使用中とみなすよう直しました）。
- **保存したプロジェクトを開くたびに、ぼかしの解析が走り直していた問題を修正しました**。
  - 照合に使う指紋が毎回変わるため、保存済みの解析結果が必ず捨てられていました。素材の由来で指紋を作るよう直したため、保存・改名・移動をしても解析結果が付いて回ります。
- **プレビューにぼかしが反映されるようになりました**（停止中は、書き出しと同じマスクで実際にぼかした絵を出します。再生中は目印のままです）。

### 動作要件

- Windows 11 / 64bit。音声認識とぼかしの解析は CPU で行います（CUDA は同梱していません）。初回は Whisper モデルを自動でダウンロードするため、ネット接続が必要です。
- FFmpeg/ffprobe・twitch-dl・ぼかし用モデル（YOLOX-Tiny）・VAD モデル（Silero VAD）は同梱済みです。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。今回追加した設定は、未設定でも既定値で動作します。
- **v1.5.0 で作ったプロジェクトの、「人物の枠を選んだぼかし指定」は引き継げません**。開いたときに 1 度だけ知らせますので、囲み直してください。マウスで囲んだ領域の指定はそのまま引き継ぎます。
- **保存済みのぼかしの解析結果は作り直します**（形式が変わったため、追従がもう一度走ります）。
- 保存済みプロジェクト（`.timeline.json`）は v1.5.0 のものをそのまま開けます。縦プロジェクトを旧バージョンで開いても壊れません（切り抜きが効かない普通の縦プロジェクトとして開きます）。
- 追加・変更された主な設定:
  - `vertical.crop.*` … 縦動画の切り抜き（`background` 既定 `blur` = ソースをぼかして敷く / `max_scale` 拡大率の上限 2.0 / `project_suffix` 既定 `_vertical` / `close_gaps` 空白を詰めるか）
  - `points.subscribe_url` … サブスクページの URL（空のあいだはボタンを出しません）
  - `blur.*` … 書式 v5 へ。旧キーは読み替えます（人物・輪郭まわりのキーは無視されます）
  - `volume_analysis.last_cut_db` … 既定を -14 → **-18 dB** へ（末尾の無音カットの判定）
