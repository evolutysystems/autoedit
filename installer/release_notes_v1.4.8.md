## Stretheus v1.4.8 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 新機能（トラッキングぼかし）

- **動画に映り込んだ人物や建物を追いかけてぼかす**機能を追加しました。**既定では OFF** です。
  - 「設定 → ぼかし」の「**トラッキングぼかしを使用する**」をオンにすると使えます。オフのままなら解析もボタンも出ず、これまでと同じ動作です。
  - オンにして Timeline 編集画面を開くと、裏で人物の解析が始まります。終わると「**ぼかし指定...**」ボタンが使えるようになります。
  - 人物は顔ではなく、**服装を含めた体全体**で同じ人かどうかを判断します。
  - **一番長く映っている人物（主役）はぼかしません。**
  - ぼかし指定画面では、フレームの上をドラッグして囲むと、「ぼかす」「ぼかさない」を指定できます。
    - 囲んだ人物への指定は、Timeline 上の**すべてのセクションへまとめて反映**されます。
    - 人物がいない場所（建物など）を囲むと、その場所を追いかけてぼかします。
  - 設定画面では、ぼかしの種類・強さ・囲っていない人物の扱い（既定は「ぼかす」）・解析の細かさを変えられます。
  - ぼかしは字幕やコメントアイコンの下に入ります。**字幕はぼけません。**
  - 何らかの理由でぼかせなかった場合は、そのまま出力せず、**「ぼかさずに出力する / 中止する」を確認**します。
  - 解析は CPU で行うため、動画の長さに応じて時間がかかります。「解析の細かさ」を下げると速くなります。
- **同梱しているソフトウェアのライセンス表記**を、インストール先の `licenses` フォルダに入れました。「設定 → ぼかし → ライセンス表記を開く」から開けます。

### 動作要件

- Windows 11 / 64bit。音声認識とぼかしの解析は CPU で行います（CUDA は同梱していません）。初回は Whisper モデルを自動でダウンロードするため、ネット接続が必要です。
- FFmpeg/ffprobe・twitch-dl・ぼかし用モデル（YOLOX-Tiny / OSNet）は同梱済みです。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。今回追加した設定は、未設定でも既定値で動作します。
- 追加された設定（主なもの。すべて `blur` の下）:
  - `enabled` … トラッキングぼかしを使うか（既定 false）
  - `default_policy` … 囲っていない人物の扱い（既定 `blur_others` = 主役以外をぼかす / `manual_only` = 囲ったものだけ）
  - `render.mode` / `render.strength` … ぼかしの種類と強さ（既定 `gaussian` / 50）
  - `analysis.sample_fps` … 1 秒あたりに解析する枚数（既定 5）
- 保存済みプロジェクト（`.timeline.json`）は v1.4.7 のものをそのまま開けます。
- ぼかしを使わない場合、テロップ・書き出しなどの動画処理は変わりません。
