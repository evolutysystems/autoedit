## Stretheus v1.5.0 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 新機能（トラッキングぼかし）

- **人物を四角ではなく、身体の輪郭に沿ってぼかせるようになりました**。
  - 「設定 → ぼかし → 人物の形」で選べます。既定は「身体の輪郭に沿う」です（従来の「角の丸い四角」「四角」「楕円」も選べます）。
  - 並んで重なっている人物も、1 人ずつ分けてぼかします。
  - 激しく動いてもぼかしが外れないよう、人物の大きさと動きに応じて輪郭の外側に余白を取ります。特に激しく動いている瞬間は、その人だけ余白付きの四角でぼかします。
  - 輪郭の解析のため、**ぼかしの解析時間が約 1.7 倍**になります（開発時の検証素材での値）。
- **「ぼかす」と「ぼかさない」が重なった部分は、ぼかさない方を優先**するようになりました。
  - これまでは、ぼかす人物の枠が「ぼかさない」人物に重なると、その部分がぼけていました。
  - 「ぼかさない」で追加した場所も、その範囲を守るようになりました（これまでは何も効いていませんでした）。
- **ぼかし指定画面で、枠の削除と追加ができるようになりました**。
  - 枠をクリックで選び、「枠を削除」・Delete キー・右クリックメニューから削除できます。削除した枠は「削除した枠」の一覧から元に戻せます。
  - 「操作」で「人物・物を追加」を選んで囲むと、検出されなかった人物や物を足せます。足した物そのものを追いかけてぼかします。
  - 「場所を追加」は、建物や看板などを足して、カメラの動きに合わせて追いかけます。
  - 追いかけられなかったときは、「この位置に固定で置く」か「取り消す」を選べます。
  - 1 人にまとめられてしまった 2 人は、枠を選んで「別の人物にする」で分けられます。
- **ぼかし指定画面の使い勝手**
  - 枠のダブルクリックで「ぼかす / ぼかさない」を切り替えます。
  - 「仕上がり表示」で、書き出しと同じ計算で実際にぼける範囲を赤く重ねて確認できます。
  - 画面の中で Ctrl+Z / Ctrl+Y（元に戻す / やり直す）が効きます。

### 修正

- **ぼかし指定画面で、削除した領域の枠が赤いまま残る問題を修正しました**（出力ではぼけていませんでした）。
- **領域を削除してから追加し直すと、前に囲んだ位置に枠が出る・追いかけられない問題を修正しました**。
- **領域の枠をクリックすると、正しく指定が変わらなかった問題を修正しました**。
- **近くに並んで座った 2 人が、1 人の人物にまとめられる問題を修正しました**。
- **「同じ人物にする」の指定が反映されていなかった問題を修正しました**。
- **解析をやり直すと、追加した領域がぼけなくなる問題を修正しました**。
- **ライトモードで、確認ダイアログや進捗ダイアログの背景が黒くなり、文字が読めない問題を修正しました**。

### 動作要件

- Windows 11 / 64bit。音声認識とぼかしの解析は CPU で行います（CUDA は同梱していません）。初回は Whisper モデルを自動でダウンロードするため、ネット接続が必要です。
- FFmpeg/ffprobe・twitch-dl・ぼかし用モデル（YOLOX-Tiny / OSNet / MobileSAM）・VAD モデル（Silero VAD）は同梱済みです。
- 輪郭用のモデルを同梱したため、ダウンロードの容量が約 45MB 増えています。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。今回追加した設定は、未設定でも既定値で動作します。
- **既にインストールしている場合、「人物の形」は以前の設定（角の丸い四角）のままです。**輪郭でぼかすには「設定 → ぼかし → 人物の形」で「身体の輪郭に沿う」を選んで保存してください。
- **保存済みのぼかしの解析結果は、開いたときに自動で解析し直します**（形式が変わったため）。
  - 人物のまとめ方を直したため、解析し直すと**人物の番号が変わる**ことがあります。その場合、Timeline 画面のボタンが「ぼかし指定... (確認してください)」になります。見本画像を見て、「ぼかす / ぼかさない」の指定を確認してください。
- 保存済みプロジェクト（`.timeline.json`）は v1.4.9 のものをそのまま開けます。
- 追加された主な設定（すべて `blur` の下）:
  - `render.shape` … 人物の形（既定 `silhouette` = 身体の輪郭 / `rounded` / `rect` / `ellipse`）
  - `render.keep_motion_margin` … 「ぼかさない」人物が激しく動いたときに守る範囲を広げるか（既定 false。true にすると守る人物はぼけにくくなりますが、重なったぼかす人物が見えやすくなります）
  - `silhouette.margin_box_ratio` / `silhouette.motion_lookahead_sec` / `silhouette.fast_motion_box_ratio` … 輪郭の外側の余白の大きさと、動きへの追従
  - `silhouette.every_n_samples` … 輪郭を作る間隔（既定 4。小さくすると形は細かくなりますが、解析が遅くなります）
- ぼかしを使わない場合、テロップ・書き出しなどの動画処理は変わりません。
