## Stretheus v1.5.5 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

> **機能の追加・変更はありません。** セキュリティと配布物の衛生に関する更新のみです。
> v1.5.4 からそのまま更新して問題ありません。操作も設定もこれまでと変わりません。

### 修正（同梱していた初期設定に開発環境のパスが残っていた）

- 同梱の `setting.json` に、**開発に使っている PC のフォルダのパスが 4 つ残っていました**
  （入力・出力フォルダと、オープニング・エンディング動画の指定）。
  v1.5.5 では**すべて空**にしています。
- お客様の情報が漏れるものではありません。残っていたのは**こちら側のフォルダ構成**だけで、
  パスワードやアカウント情報は含まれていません。
- 動作への影響もありません。これらの項目は**初回起動時に空から設定するもの**で、
  これまでも存在しないパスが入っていれば無視されていました。
- 以後は同じことが起きないよう、**ビルド時に自動で空へ戻す**ようにしています。
  想定外の場所のパスが混じっていた場合はビルドを止めます。

### 修正（同梱ライブラリの既知の脆弱性）

同梱している Python ライブラリのうち、**既知の脆弱性が公表されていた 5 つを更新**しました。

| ライブラリ | 用途 |
|---|---|
| urllib3 | 音声認識モデルの取得時の通信 |
| anyio / idna | Twitch からの取得時の通信 |
| msgpack | データの読み書き |
| fsspec | ファイルの取り扱い |

- **いずれも、悪用された形跡はありません。** 公表された内容を確認したところ、
  Stretheus の使い方では**到達できない経路**か、**悪意のあるサーバーに繋いだ場合に
  処理が重くなる**という種類のものでした。
- 予防として、修正済みの版へ上げています。

### 変更（配布物を少し軽くしました）

- ビルド時にだけ必要なライブラリ（`setuptools` / `pkg_resources`）が
  配布物へ入っていたため、**同梱から外しました**。
- 動作に影響はありません（外した状態で全テスト 1,115 件が通ることを確認しています）。

### 確認方法（ダウンロードしたファイルが壊れていないか）

インストーラーは、取得した本体 zip の **SHA-256 を自動で検証**します。
検証に失敗した場合はインストールを中止します。

`StretheusSetup.exe` の SHA-256 は次の値です。気になる場合は照合してください。

```
AD40A2131D324B86B2427D404FB1985537F41B1A4D3B9B6C6B6BC7348055FD4E
```

```powershell
(Get-FileHash .\StretheusSetup.exe -Algorithm SHA256).Hash
```
