## Stretheus v1.5.2 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 新機能（サブスクリプション）

- **メイン画面の右上に「サブスクリプション」ボタンが付きました**（設定ボタンの左、残高表示の右）。
  - 押すとサブスクリプション画面が開きます。月額の金額と説明はサーバーから取り出して表示するため、アプリを入れ直さなくても最新の内容が出ます。
  - 画面には「Twitch でログイン」と「購入」の 2 つのボタンがあります。
- **Twitch で `tatsumic` をサブスクリプションしている方は、購入の必要がありません**。
  - ログインすると購入ボタンが押せなくなり、「Twitch のサブスクリプションで特典が適用されています」と表示します。Twitch のサブスクリプションが切れると、この画面から購入できるようになります。
- **加入中はメイン画面のボタンにチェックマークが付き、押せなくなります**。
  - Twitch のサブスクリプションは Twitch の色（紫）、購入した場合は画面のテーマに合わせた色でチェックマークが出ます。
- **設定 → アカウントに「サブスクリプション状態」と「サブスクリプション履歴」が増えました**。
  - 種別（Twitch / 購入）・状態・次回更新日と、加入や更新の履歴を確認できます。
  - 解約やカード変更の「サブスクリプションを管理」はこれまでどおりアカウントタブにあります。登録はメイン画面から、確認と管理は設定画面から、と役割を分けました。
  - これまで「履歴」だった見出しは「ポイント履歴」に変わりました。
- サーバー側の準備が整っていない間や、ネットにつながらない間は、購入ボタンは押せない状態のまま理由を表示します（アプリが止まることはありません）。
- **未加入・未ログインのままなら、これまでと何も変わりません**。ポイントの扱いも従来どおりです。

### 新機能（アーカイブ切り抜きからも縦動画プロジェクトを作れます）

- **アーカイブ切り抜き用の Timeline でも、右クリックの「縦動画プロジェクトを作成...」が使えるようになりました**（v1.5.1 では「クリップ用」だけでした）。
  - 作られる縦プロジェクトは **元の配信アーカイブ（VOD）を参照**します。そのため、実行の終わりに中間ファイルが消えた後でも、そのまま開いて続きを編集できます。
  - 絵は編集画面で見たものと同じ位置になります（動画のキーフレームに合わせて時刻を取り直しています）。
  - 元の VOD がもう無い場合は、このメニューを出しません（参照先を作れないため）。
  - **音量の正規化は引き継ぎません**。アーカイブ側はクリップごとに測って揃えているため、VOD 全体へは当て直せないためです。作成時にお知らせします。必要なときは縦プロジェクト側でクリップの音量を調整してください。
  - 切り抜いた動画ファイルは作りません（v1.5.1 と同じく、切り抜きの指定だけを覚えます）。
- **「クリップ用」から作る場合の動き、アーカイブ切り抜きの採点・編集・書き出しは、1 つも変わりません**。

### 動作要件

- Windows 11 / 64bit。音声認識とぼかしの解析は CPU で行います（CUDA は同梱していません）。初回は Whisper モデルを自動でダウンロードするため、ネット接続が必要です。
- FFmpeg/ffprobe・twitch-dl・ぼかし用モデル（YOLOX-Tiny）・VAD モデル（Silero VAD）は同梱済みです。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。今回追加した設定は、未設定でも既定値で動作します。
- 保存済みプロジェクト（`.timeline.json`）は v1.5.1 のものをそのまま開けます。書式は変えていません。
- **新しく入れた場合の「末尾の無音カットの判定」(`volume_analysis.last_cut_db`) を、アプリ本来の既定値 -28 dB に直しました**。
  v1.5.1 までの配布物には開発時の測定値（-18 dB など）がそのまま入っていました。更新の場合は今お使いの値がそのまま残ります。
- 追加された設定:
  - `billing.config_cache_sec` … 金額・説明の再取得の間隔（既定 3600 秒）
  - `billing.activation_poll_sec` / `billing.activation_timeout_sec` … 購入後の反映待ちの間隔と上限（既定 3 秒 / 180 秒）
  - `vertical.crop.keyframe_window_sec` … アーカイブから縦プロジェクトを作るとき、キーフレームを探しに戻る幅（既定 30 秒）
