## Stretheus v1.4.6 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 変更点（メイン画面のデザイン刷新）

- **クリップ用タブを作り直しました**。画面の上から順に、ドラッグ＆ドロップ領域 → 「続きから」 → 実行 → 進捗バー → 実行状況ラベル、という並びになりました。
  - **画面上部 60% が「ドラッグ＆ドロップでファイルを選択」の領域**になりました。**画面のどこへ落としても**受け付けます（タブの帯の上でも構いません）。ドラッグ中は枠がオレンジになり、落とせることが分かります。
  - 落とすと**文言がファイル名に変わり、右に × ボタン**が出ます。× を押すと選択が消えて元の案内文へ戻ります。
  - **入力欄と「参照...」ボタンは隠しました**。設定 `ui.main_window.show_file_row` を `true` にすると従来どおり表示できます。
  - 「編集の続き」の行（コンボ・開く・一覧）は**「続きから」ボタン 1 つ**に置き換えました。押すと従来の「一覧...」と同じプロジェクト一覧が開きます。
  - **一覧でプロジェクトを選んでも、その場では実行しません**。文言にプロジェクト名が出るだけで、開始は実行ボタンを押したときです（動画を落としたときと同じ操作感になります）。× で取り消せます。
  - 動画とプロジェクトは**どちらか一方だけ**が選ばれます。実行ボタンは選んだものに応じて、通常のパイプラインか「編集の続き」かを自動で切り替えます。
  - 「続きから」と実行ボタンは**同じ幅で画面中央**に並びます。
  - 進捗バーと実行状況ラベルのデザインは従来どおりです。
- **メイン画面が 700 × 520 で開くようになりました**（従来は中身に合わせたサイズ）。ウィンドウを伸縮しても、ドラッグ＆ドロップ領域は高さの 60% を保ちます。小さくしたときは実行ボタンなどが隠れないよう領域側を縮めます。

### 修正

- **チェックボックスにチェックマークが表示されるようになりました**。これまでは背景がオレンジに変わるだけで印が付いていませんでした。設定画面・アーカイブ切り抜き用タブなど、アプリ内のすべてのチェックボックスが対象です。
- **ドロップダウン（コンボボックス）の右端が浮き出て見える問題を修正しました**。押しボタン状の面が消え、文字色の三角だけが表示されます。こちらもアプリ全体が対象です。
- **設定ボタン（右上の歯車）とタブの枠がくっついていたのを直しました**。ボタンの下に余白が入ります。

### 動作要件

- Windows 11 / 64bit。音声認識は CPU 実行（CUDA非同梱）。初回は Whisper モデルの自動DLにネット接続が必要。
- FFmpeg/ffprobe・twitch-dl は同梱済み。

### 更新について

- 既存インストールの `setting.json`（出力先など）は保持されます。今回追加した設定（`ui.main_window`）は起動時に既定値で自動補完されます。
- 追加された設定（すべて `ui.main_window` の下）:
  - `width_px` / `height_px` … メイン画面の初期サイズ（既定 700 / 520）
  - `drop_zone_ratio` … ドラッグ＆ドロップ領域が占める割合（既定 0.6）
  - `drop_zone_min_height_px` … 同領域の最小の高さ（既定 140）
  - `show_file_row` … 隠した入力欄と「参照...」を表示するか（既定 false）
- 保存済みプロジェクト（`.timeline.json`）の形式は v1.4.5 と互換です（`schema_version` は据え置き）。
- テロップ・書き出し・採点など、動画処理そのものの挙動は変更していません。
