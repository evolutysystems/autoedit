## Stretheus v1.4.1 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 新機能

- **新しいクリップ編集画面（Timeline 編集）**：これまでの字幕一覧に代わり、上部にプレビュー・下部に Timeline を置いた編集画面を表示するようになりました。DaVinci Resolve / Premiere Pro のようなノンリニア編集の操作感で、映像・音声・字幕をまとめて調整できます。
  - **トラック**：映像 (V) / 音声 (A) / 字幕 (S)。音声クリップは映像に追随するため、編集しても音ズレが起きません。
  - **クリップ編集**：ドラッグで移動、左右端のドラッグで長さ変更、分割、削除／リップル削除。編集点・再生ヘッド・クリップ端へ自動で吸着します（Alt 押下で吸着オフ）。
  - **Timeline 操作**：拡大・縮小（Ctrl+ホイール）、横スクロール、再生ヘッド移動。画像・動画をドラッグ＆ドロップで追加でき、必要に応じて新しい映像トラックが作られます。
  - **プレビュー**：再生ヘッド位置の映像を表示し、画像・字幕はクリックで選択、ドラッグで位置変更。右クリックから削除・レイヤー順（最前面／前面／背面／最背面）を変更できます。再生・倍速再生・倍速逆再生に対応。
  - **やり直し**：すべての編集操作が「元に戻す／やり直す」に対応しました。
  - **ショートカット**：W 分割 / A 再生ヘッドより前をリップル削除 / D 後ろをリップル削除 / Delete リップル削除 / BackSpace 削除のみ / Space 再生 / Q・E 倍速逆再生・倍速再生。文字入力欄やドロップダウンにフォーカスがある間は無効になります。
  - 「決定」を押すと、Timeline の内容を反映した動画を書き出します。
- **無音カットを「編集点」方式へ変更**：無音区間を実際に切った動画を作らず、カット位置を編集点として保持して Timeline に反映するようにしました。カットのやり直しが編集画面上で完結し、最終出力時にまとめて書き出されます。
- **音声クリップに波形を表示**：音声ノードの背景に音量の波形（横軸＝時間／縦軸＝音量）を表示するようにしました。素材の音声は 1 回だけ解析され、クリップの移動・分割・トリムをしても波形はずれません。右クリックの「音量」で dB を変えると波形の高さにも反映され、ミュート中は灰色になります。`setting.json` の `timeline.waveform.enabled=false` で無効化できます。
- **字幕のフォントをドロップダウンで選択**：編集画面右側のプロパティで、フォント名を手入力する代わりに一覧から選べるようにしました（設定画面と同じく、各項目はそのフォント自身で描画されます）。空欄にあたる「(設定のフォント)」を選ぶと設定画面のフォントに従います。

### デザイン

- **全画面をガラスモーフィズム調へ刷新**しました。Windows の外観設定（ライト／ダーク）に追従します。
- メイン画面の「設定」ボタンをタブの外へ移動し、どのタブを選んでいても設定画面を開けるようにしました。
- アーカイブ切り抜きタブの「採点開始」をクリップ用タブと同じ再生アイコンに統一、設定画面の配信者／サブ／コメントの各カラーを横並びに変更、その他アイコンボタンの見切れ・角丸の調整を行いました。

### 修正

- Timeline を右端までスクロールすると左へ戻れなくなることがある問題を修正しました。
- 編集画面右側のプロパティの角が丸くなっていたのを、周囲と接する面として角丸なしに修正しました。

### 動作要件

- Windows 11 / 64bit。音声認識は CPU 実行（CUDA非同梱）。初回は Whisper モデルの自動DLにネット接続が必要。
- FFmpeg/ffprobe・twitch-dl は同梱済み。
- プレビュー再生には同梱の Qt Multimedia を使用します。再生できない環境では静止画表示に自動で切り替わります。

### 更新について

既存インストールの `setting.json`（出力先など）は保持されます。新規キー（`timeline.waveform` 等）は起動時に既定値で自動補完されます。

従来の字幕一覧の編集画面も残してあり、`setting.json` の `timeline.enabled=false` で元の画面に戻せます。
