## Stretheus v1.8.6 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。
設定・ログイン情報・保存済みプロジェクトは引き継がれます。

> 今回は **テロップに動き (アニメーション) を付けられるようになった**のが新機能、
> **Timeline でテロップが意図せず別トラックへ移ってしまう不具合**と
> **「続きから」で選んだプロジェクトがすぐ開かない問題**の修正が修正点です。

---

### 新機能（テロップアニメーション）

- 編集画面でテロップを選び、インスペクタの **「アニメーション」** から動きを選べます。
  次の 12 種類があります。
  - 震える / 発光登場 / つっこみ / 発光ブラー / 衝撃1 / 衝撃2 / ぴかっと /
    ポヨン / 飛び込みツッコミ / 2回ジャンプ / 黒ブラー拡大 / 黒ブラー縮小
- **フェードイン / フェードアウト** はチェックで付けられ、上の動きと一緒に使えます。
- 複数のテロップを選んでいるときは、選んだすべてに同じ動きが付きます (Ctrl+Z で戻せます)。
- 編集画面のプレビューで動きを確認でき、書き出した動画にも入ります。
- 動きの速さ・大きさ・ぼかしの量は `setting.json` の `subtitle.animation` で変えられます。

> 操作の詳細は取扱説明の「Timeline 機能ガイド」3.2 に記載しました。

### 修正（テロップが意図せず別トラックへ移る問題）

- **症状**: テロップのアニメーションを選んだあと、アニメーションの欄が灰色になり
  変えられなくなることがありました。
- **原因**: Timeline 上のドラッグ操作が、マウスのボタンを離したあとも続いていると
  誤って扱われることがあり、テロップがコメント用のトラックへ移っていました
  (コメントのテロップはフェードだけが使えるため、欄が無効になっていました)。
- ボタンを押していないのにドラッグが続いているときは、その操作を取り消すようにしました。

### 修正（「続きから」で選んだプロジェクトがすぐ開かない問題）

- クリップ用タブの「続きから」の一覧でプロジェクトを **ダブルクリック / 「開く」** すると、
  そのまま編集を再開するようにしました (これまでは選んだあと「実行」を押す必要がありました)。
- アーカイブ用タブは、以前から一覧で開くとそのまま再開します (変更はありません)。

### この版で分かっていること

- **テロップの動きは DaVinci Resolve 出力 (FCPXML) には引き継がれません**
  (書き出し前に確認が出ます)。
- **コメント役割のテロップはフェードだけ**使えます（背景の箱とアイコンが動きに追従できないため）。
- 試作版にあった Word Pop / Bounce / Big Word は廃止しました。
  これらを付けたプロジェクトは「動きなし」で開きます (フェードは残ります)。
- **実行ファイルはまだコード署名されていません**（証明書の調達待ちです）。
  インストール時に Windows の SmartScreen 警告が出ることがあります。
- **アンインストールしても、ログイン情報と編集したファイルのパス一覧は端末に残ります**
  （次の更新で対応予定）。
- **ゲーム内のボイス（NPC の台詞など）はテロップになります**（編集画面で手で落としてください）。
- 切り抜き区間の頭が最大 2 秒ほどずれる点（`-c copy` 由来）は、今後の課題として残しています。
- 設定の「話者照合（特定の人の声だけ残す）」は **配布版では動きません**（v1.8.3 からの継続）。
