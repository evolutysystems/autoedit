## Stretheus v1.8.5 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。
設定・ログイン情報・保存済みプロジェクトは引き継がれます。

> 今回は **Timeline へ SE (効果音) を置けるようになった**のが新機能、
> **保存したプロジェクトへセクションを追加できなくなっていた不具合**の修正が修正点です。

---

### 新機能（Timeline に SE＝効果音を置けるようになりました）

- 音声ファイル (`.mp3` / `.wav` / `.m4a` / `.aac` / `.flac` / `.ogg` / `.opus` / `.wma`) を
  **Timeline へドラッグ＆ドロップ**すると、落とした時刻に SE が置かれます。
  SE トラックの空き領域で右クリック →「SE を追加...」からも選べます。
- **音量を変えられます**。SE を右クリック →「音量 ▶ +6 / +3 / 0 / -3 / -6 dB」で決め打ち、
  SE を選んでインスペクタの「音量」スライダ (既定 -40〜+12 dB / 0.5 dB 刻み) で
  再生しながら追い込めます。どちらも Ctrl+Z で戻せます。「ミュート」もできます。
- **移動・トリム・分割・コピー＆ペースト・リップル削除は映像クリップと同じ操作**です。
  SE ノードには波形と、素材名＋現在の音量 (例 `pon (-6.0 dB)`) が出ます。
- **編集画面の再生で SE が聞こえ、書き出した動画にも入ります**。
  プロジェクトを保存して開き直すと、位置・音量・ミュートがそのまま戻ります。
- SE トラックは既定 1 本 (SE1) で、トラックヘッダの右クリックから 4 本まで増やせます。
  同じトラック内で音を重ねることはできないため、重ねたいときはトラックを増やしてください
  (空きが無ければ自動で増えます)。
- 本編より後ろへ置いた SE は鳴りません (SE で出力の尺が伸びることはありません)。

> 操作の詳細は取扱説明の「Timeline 機能ガイド」4.5〜4.6 に追記しました。

### 修正（保存したプロジェクトにセクションを追加できなかった問題）

- **症状**: 保存済みのプロジェクトを開いてセクションを追加すると、元動画の取得が
  **終わった直後に**「セクションを準備できませんでした」「取得した区間のファイルが
  見つかりませんでした」と出て、追加できませんでした。
- **原因**: Twitch 側の配信データの形式が変わっており (従来の `.ts` から断片化 MP4 へ)、
  区間を取り直す処理が**古い形式だけを前提にしていた**ためです。
  形式が変わった VOD では、**何度やっても同じ場所で失敗する**状態でした。
- **あわせて修正**: 失敗したときに取得済みのデータが中途半端に残り、
  **やり直しても必ず同じ失敗を繰り返す** (そのたびに数 GB を落とし直す) 状態でした。
  失敗時は残骸を片づけ、やり直しが通るようにしました。
  すでに落とし終えている部分は**落とし直しません**。
- **あわせて修正**: 配信が途中で途切れている箇所をまたぐ区間も、正しくつなげるようにしました。
  動画の末尾ぎりぎりまでの区間も追加できます。
- **影響していた操作**: 元動画を手元に残していない (保存して開き直した) プロジェクトでの
  **セクションの追加**と、**イントロカード用の映像の取り直し**です。
  元動画が手元にある場合、および動画 1 本をまるごと取得する処理は影響を受けていません。

### この版で分かっていること

- **実行ファイルはまだコード署名されていません**（証明書の調達待ちです）。
  インストール時に Windows の SmartScreen 警告が出ることがあります。
- **アンインストールしても、ログイン情報と編集したファイルのパス一覧は端末に残ります**
  （次の更新で対応予定）。
- **ゲーム内のボイス（NPC の台詞など）はテロップになります**（編集画面で手で落としてください）。
- 切り抜き区間の頭が最大 2 秒ほどずれる点（`-c copy` 由来）は、今後の課題として残しています。
- 設定の「話者照合（特定の人の声だけ残す）」は **配布版では動きません**（v1.8.3 からの継続。
  実測で精度が出ず既定オフのままだった機能です）。
