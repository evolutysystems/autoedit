## Stretheus v1.4.3 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

**v1.4.2 からの修正リリースです。** v1.4.2 の新機能は[こちら](https://github.com/evolutysystems/autoedit/releases/tag/v1.4.2)を参照してください。

### 修正

- **アーカイブ切り抜きで「Twitch の Client-ID が未設定です」と出る問題を修正しました。**
  - 原因: Twitch の Client-ID は配布する `setting.json` にしか持っていませんでした。更新インストールでは、利用者の設定（出力先など）を守るためにインストーラーが**既存の `setting.json` をそのまま復元する**ため、新しい版へ更新しても Client-ID が届かず、空のまま残っていました。新規インストールでは正常だったため、更新した環境でのみ発生していました。
  - 対処: Client-ID をアプリ側の既定値として持たせ、**空のまま残っている環境は次回起動時に自動で補完**するようにしました。更新後にアプリを一度起動すれば直ります。手作業での `setting.json` 編集は不要です。
  - 自分で登録した Client-ID を設定している場合は、その値をそのまま使い続けます（上書きしません）。

### 補足

同じ形の不具合（新しい既定値が更新環境へ届かない）は、過去に FFmpeg のパスでも起きています。今回あわせて、設定の補完まわりに自動テストを追加しました。

なお、テロップの色・フォントサイズ・音量まわりなど**利用者が調整する設定**は、これまでどおり更新しても保持されます（新しい既定では上書きされません）。

### 動作要件

- Windows 11 / 64bit。音声認識は CPU 実行（CUDA非同梱）。初回は Whisper モデルの自動DLにネット接続が必要。
- FFmpeg/ffprobe・twitch-dl は同梱済み。
