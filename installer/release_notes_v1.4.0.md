## Stretheus v1.4.0 (CPU版・インストーラー配布)

`StretheusSetup.exe` をダウンロードして実行してください。インストーラーが本体を自動取得・展開します。

### 新機能
- **字幕編集画面に動画プレビューを追加**：クリップ用の字幕一覧画面・アーカイブ切り抜きの結果画面の両方で、**字幕を適用した状態**の映像を確認できるようになりました。字幕行を選ぶとその時刻から約20秒の区間を再生し、「プレビュー更新」で編集中の字幕（テキスト・使用可否・色・フォント）を反映して作り直せます。テーマ演出（イントロ/タグ）はプレビューに含まれません。
- **DaVinci Resolve プロジェクト出力**：字幕一覧画面・結果画面の「DaVinci Resolve ファイル出力」ボタンで、カット編集点と字幕を FCPXML（+ SRT サイドカー）として出力できます。Resolve の File > Import > Timeline から取り込めます。
- **音声レベルの自動調整（ラウドネス正規化）**：クリップ用・アーカイブ切り抜き用とも、最初の工程で YouTube 推奨基準（Integrated −14 LUFS / True Peak −1.0 dBTP）へ音声を正規化するようにしました。`setting.json` の `loudness.enabled=false` で無効化できます。
- **アーカイブ切り抜きの無音カット精度向上**：各クリップの音量を自動解析してカット閾値を確定するようにしました（確認ダイアログは出ません。保存済みの閾値設定は変更されません）。

### 動作要件
- Windows 11 / 64bit。音声認識は CPU 実行（CUDA非同梱）。初回は Whisper モデルの自動DLにネット接続が必要。
- FFmpeg/ffprobe・twitch-dl は同梱済み。
- プレビュー再生には同梱の Qt Multimedia を使用します。再生できない環境では静止画表示に自動で切り替わります。

### 更新について
既存インストールの `setting.json`（出力先など）は保持されます。新規キー（`preview` / `loudness` 等）は起動時に既定値で自動補完されます。
