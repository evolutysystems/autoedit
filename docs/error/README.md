# docs/error — 障害報告と修正設計 (履歴)

このフォルダは **障害 1 件ごとの記録**であり、現行仕様書ではない。

* `<YYYYMMDD>/error.md` = 現象の報告 (ログ・再現手順)
* `<YYYYMMDD>/resolve.md` = 原因の特定と修正設計
* `fromUser/` = 利用者から直接寄せられた報告

日付ごとの主題は `docs/README.md` §3.2 の一覧にまとめてある。

> **読み方**: ここにある値・既定値・モジュール名は**その時点のもの**である。
> 現行仕様は `docs/design/design.md`、設定の既定値は
> `src/settings/settings_window.py` の `DEFAULT_SETTINGS` を見ること。
> 文書全体の索引と「新旧が反転した決定」の一覧は `docs/README.md` にある。
