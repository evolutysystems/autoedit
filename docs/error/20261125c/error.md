# error 20261125c — AI 編集のテロップが音声と合わない

発生日: 2026-11-25 / 対象: `vod_2938816056.ai_youtube_long` (経路 D / YouTube 長尺)

## 症状 (利用者の報告)

> 編集がぐちゃぐちゃになっていてヒドイです。音声とテロップが全く合っていません。

## 調べた素材

| ファイル | 役割 |
|---|---|
| `vod_2938816056.ai_youtube_long.timeline.ai-base.json` | AI の計画を当てた後の Timeline (S1 = 105 本) |
| `vod_2938816056.ai_youtube_long.timeline.plan.json` | AI が出した計画 (`subtitles` 86 件 / 本文 79 種) |

## 原因は 3 つ重なっている

### ① AI のテロップが既存テロップの枠を乗っ取る (`plan_applier`)

`_apply_subtitles` は AI の素材時間を Timeline 時間へ写し、**`pieces[0]` だけ**を使う。
無音カット (編集点モード) が入った素材では 1 つの素材区間が複数の Timeline 片へ割れるため、
`pieces[0]` は**先頭の破片**になる。そこへ `_subtitle_at` が「少しでも重なる既存テロップ」を
拾って本文だけ差し替えるため、**枠 (時刻と尺) は破片のまま**で中身が入れ替わる。

実測 (S1 105 本):

| 計測 | 値 |
|---|---|
| 本文が `origin.asr_text` と違う = AI が上書きした | **51 本** |
| そのうち本文が `plan.subtitles` に載っている | **51 / 51 本** (全て) |
| 上書きされた枠の尺 | 中央値 2.22 秒 / **最小 0.30 秒** / 1 秒未満 8 本 |
| 入れられた本文の長さ | 中央値 17 文字 / **最大 40 文字** |
| 毎秒 20 文字を超える (読めない) | **8 本** |

最悪の例:

```
枠 TL 0.00 尺 0.30 秒  ← 素材 7.694-7.990 の破片
  AI 本文 'フロントウィングないやん' (12 文字)
  元       'フ'
```

AI は素材 7.69-12.28 のつもりで出したのに、**0.30 秒の破片**へ入った。
本来の発話より **7 秒以上早く**、しかも 0.3 秒で 12 文字が出る。

### ② AI へ渡す文字起こしが 1 つの塊に潰れている (`context_builder`)

`_merge_transcript(items, gap)` は `item.start - 直前.end <= gap` なら無条件に結合する。
**長さも文字数も上限が無い。** 既定 `merge_transcript_gap_sec = 1.0` は連続した発話では
ほぼ常に成立するため、実測では

```
元の認識単位 99 件 → 1 件
  長さ 149.1 秒 / 1,538 文字
```

**AI は「149 秒のどこで何を言ったか」を知る術がない。**
`subtitles[].source_start` / `source_end` は推測にしかならず、①がその推測を
さらに破片へ押し込む。②が①の前提条件である。

### ③ 既存テロップ自体が語の途中で切れている (`subtitle_generator`) — 見送り

> **直さない。** 利用者の判断 (2026-11-25):
> 「文字起こしは既存の処理でいい。安定しているので」。
> 以下は調べた結果の記録であり、症状は残っている。

AI に触られていない 48 本の中に、読めない破片が残っている。

```
TL 69.44 尺 0.33s  'ド'                        素材 132.877-133.207
TL 69.77 尺 1.70s  'ライブアウトからでしょまず走'   素材 142.070-143.768
TL 71.47 尺 0.84s  'る'                        素材 147.386-148.004
```

「ドライブアウトからでしょまず走る」が **3 本に割れている**。他にも
`'ぁー順'` (0.48 秒) / `'もうあ'` (0.57 秒) / `'んないんだけどオ'` (0.64 秒) など。

仕組み上の原因:

* 無音カットが残した **0.33 秒の小島** (無音の中の物音) に Whisper が語を 1 つ割り当てた
* `regroup_items_by_length` はカット境界 (`crossed`) と長い無音 (`torn`) で必ず区切るため、
  その小島が**単独のテロップ**になる
* 結果、**Timeline 上では隣接しているのに**本文が 1 文字と 14 文字に割れる
  (69.44 + 0.33 = 69.77 = 次のテロップの頭)

## 影響

* ①は AI 編集 (経路 D) だけ。従来の切り抜き (経路 B) は `plan` を当てないため無関係
* ②は AI 編集だけ
* ③は **AI を使わない通常の書き出しでも起きる**。無音カット ON + `subtitle_unit = length` の組み合わせ
