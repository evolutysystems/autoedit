4Timeline 領域（原文 5 章）

5.1 トラックの並び（上から下へ）

S1 / S2字幕トラックS1 = 配信者／サブ、S2 = コメント
V2 ↑オーバーレイ映像トラックV2 以上／番号の大きい順
V1ベース映像トラック本編・オープニング・エンディング
A1 …音声トラックV1 のクリップとリンク
  • クリップの色は種類別で、選択中は輪郭が太くなります。
  • 「使用しない」にしたクリップは灰色表示になり、書き出しから外れます。
  • 音声トラックには波形を表示します（設定 timeline.waveform.enabled）。
  • 音声クリップは V1 のクリップに連動（リンク）しています。音声側を掴んでも V1 側の操作になります。
  • ロックされたトラックのクリップは、移動・トリム・字幕追加ができません。

5.4 右クリックメニュー（何もない所）

  • ここへ再生ヘッドを移動
  • 再生ヘッドへ貼り付け（Ctrl+V）
  • 字幕トラックの空き領域なら: 字幕追加 ／ すべての字幕をカット頭へ揃える
    • 追加位置は編集点へ吸着します。コメント用トラック上で足した字幕は、最初から役割「コメント」になります。

5.5 右クリックメニュー（音声クリップ上）

  • ミュート ／ ミュート解除
  • 音量 ▶ +6 dB / +3 dB / 0 dB / -3 dB / -6 dB
補足 音声クリップには削除がありません（V1 側から消します）。

6編集機能のふるまい（原文 7 章・説明時の注意点）

機能補足
分割再生ヘッド位置、または右クリックした位置で切る
リップル削除削除した尺のぶん後続が詰まる。詰める対象トラックは設定 ripple_sync_tracks（既定: 全トラック）
削除のみ跡が空白として残る。空白は書き出し時に黒（設定 render.gap_policy）
リップルトリム（A / D）再生ヘッドがクリップ上にないときは実行されず、画面下に案内が出ます（エラーにはしません）
コピー＆ペースト貼り付け位置は再生ヘッド。干渉した既存ノードは右へずれ、ずれた秒数が案内に出ます。貼り付けられなかった件数も表示されます
貼り付け失敗トラックのロック・素材の欠落が原因。その旨の案内が出ます
字幕をカット頭へ揃えるV1 クリップの頭に合わせます。対象が無いときは「カット頭へ揃える字幕はありませんでした」
Undo / Redo操作名付きで表示されます（例: 「元に戻す: クリップの移動」）
最小クリップ長0.05 秒（設定 min_clip_sec）。これより短くはトリムできません
新規字幕の尺2.0 秒（設定 default_subtitle_sec）
画像の既定尺5.0 秒（設定 media.default_image_duration_sec）
追加できる素材 動画: .mp4 .mov .avi .mkv .flv .wmv
画像: .png .jpg .jpeg .bmp .gif .webp

8DaVinci Resolve 出力（原文 11 章）

「DaVinci Resolve 出力」ボタンで、現在の Timeline を DaVinci Resolve 用プロジェクトファイル（.fcpxml）として出力します。

上書き確認が入る 透かしの確認が入る

9書き出し（決定）（原文 12 章）

  • 「決定」で Timeline の内容を反映した動画を書き出します。
  • 映像クリップが 0 件のときは書き出せません（警告）。
  • 「使用しない」にしたクリップ・字幕は書き出しから外れます。

10切り抜き編集（採点結果）画面の固有機能（原文 13 章）

Timeline 編集画面の全機能に加えて、上部にクリップバー、ドックに採点グラフが付きます。

項目説明
クリップ（コンボボックス）「clip1 0:00:10→0:01:20 点82.5」の形式で一覧。選ぶとその先頭へ再生ヘッドが飛びます
セクション追加...元動画の区間を指定してセクションを追加。元動画の時系列に沿った位置へ挿入され、既存セクションと重なる場合は 1 つに統合されます。準備中は進捗が出て中止もできます
このクリップを使用する外すと Timeline 上で灰色になり、書き出しから外れます（戻せます）
テーマ入力するとクリップ先頭にイントロカード、本編に左上タグが付きます。空欄 = テーマ演出なし
採点グラフ（ボタン / G）採点グラフドックの表示切替
採点グラフ（ドック）時系列の採点カーブとクリップのマーカ。マーカをクリックするとその位置へ移動。上下左右へドッキング位置を変更できます
完了（切り抜き＋字幕焼き込み）「決定」に相当するボタン
