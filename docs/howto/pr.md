# Request
このシステムの紹介をホームページに載せるとして、ユーザーがそのページを見たときに使いたくなるシステム紹介をしてください。
ターゲットはTwitchストリーマーです。ただしTwitchという文字は出さないでください。Youtube用でもあるからです。
SEO並びにAEO・GEOに有効な書き方をしてください。希望のワードは以下です。
- 配信者　動画編集
- Twitch 動画編集
- Youtube 動画編集
- 切り抜き　簡単
- テロップ　自動
ストリーマー向けであることが最重要です。

# Output
pr_resolve.mdとして、ホームページに載せるための設計書を出力してください。
デザインに関しては言及しなくていいです。
