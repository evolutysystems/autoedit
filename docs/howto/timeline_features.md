### 下部ボタン

| ボタン | 動作 | 出る条件 |
|---|---|---|
| 元に戻す（Ctrl+Z） | 直前の編集を取り消す。ボタンには取り消す操作名が出る | 常時 |
| やり直す（Ctrl+Y） | 取り消した編集をやり直す | 常時 |
| 保存（Ctrl+S） | Timeline をプロジェクトファイルへ保存 | `timeline.project.save_button` が ON |
| 名前を付けて保存（Ctrl+Shift+S） | 保存先を選んで保存 | 同上 |
| DaVinci Resolve 出力 | 現在の Timeline を `.fcpxml` として出力 | Resolve 出力が ON |
| 決定 | Timeline の内容で動画を書き出す（採点結果画面では「完了（切り抜き＋字幕焼き込み）」） | 常時 |
| キャンセル | 編集を破棄して処理を中断 | 常時 |

- 「決定」は Enter / Space では発動しません（長い書き出しの誤発動防止）。必ずクリックです。
- 映像クリップが 1 つも残っていない状態で「決定」すると警告が出て、書き出せません。

### プレビュー上での直接編集

| 対象 | 操作 | 結果 |
|---|---|---|
| 字幕 | ドラッグ | 表示位置を移動 |
| 画像・動画（オーバーレイ） | ドラッグ | 表示位置を移動 |
| 画像・動画（オーバーレイ） | 四隅のハンドルをドラッグ | 縦横比を保って拡大・縮小 |
| 字幕・オーバーレイ | クリック | 選択（インスペクタ・Timeline の選択と連動） |
| オーバーレイ | 右クリック | 削除 / レイヤー（最前面・前面・背面・最背面）/ 大きさ（原寸・100%（画面幅）） |


### 字幕を選んだとき

| 項目 | 説明 |
|---|---|
| 字幕 | テキスト（改行可）。入力欄から離れたときにまとめて確定（1 文字ごとに Undo 履歴が増えないように） |
| 役割 | 配信者 / サブ / コメント。変更すると対応するトラックへ自動移動（設定次第） |
| フォント | 一覧から選択。先頭の「(設定のフォント)」= 設定値に従う。各項目はそのフォント自体で描画されます |
| サイズ | 数値指定。0 で「既定」 |
| 文字色 | このクリップだけの上書き。空欄にすると設定の役割色に戻る |
| 縁の色 | 同上（透明度も指定可） |
| 位置を既定へ戻す | ドラッグで動かした位置を捨て、設定の配置・余白に従わせる |

※ 字幕を複数選択しているときは、色の変更が選択中すべてに適用されます（その旨の案内が出ます）。

### 画像・動画（オーバーレイ）を選んだとき

| 項目 | 説明 |
|---|---|
| 大きさ | キャンバス幅に対する %（100% = 画面の横幅いっぱい）。縦横比は常に保持 |
| 原寸 | 素材のピクセル数どおりの大きさにする |
| 画面幅に合わせる | 100% にする |
| 位置を既定へ戻す | 同上 |

※ 字幕・音声・本編（V1）の映像には「大きさ」は出ません。

## 5. Timeline 領域
### 5.1 トラックの並び（上から下へ）

1. 字幕トラック（S1 = 配信者／サブ、S2 = コメント）
2. オーバーレイ映像トラック（V2 以上／番号の大きい順）
3. ベース映像トラック V1（本編・オープニング・エンディング）
4. 音声トラック（A1 …）

- クリップの色は種類別で、選択中は輪郭が太くなります。
- 「使用しない」にしたクリップは灰色表示になり、書き出しから外れます。
- 音声トラックには波形を表示します（設定 `timeline.waveform.enabled`）。
- 音声クリップは V1 のクリップに連動（リンク）しています。音声側を掴んでも V1 側の操作になります。
- ロックされたトラックのクリップは、移動・トリム・字幕追加ができません。

### 5.3 右クリックメニュー（クリップ上）

| 項目 | 説明 |
|---|---|
| ここで分割 | 右クリックした位置でクリップを分割 |
| コピー（Ctrl+C） | 選択中のノードをコピー |
| 再生ヘッドへ貼り付け（Ctrl+V） | 貼り付け先は常に再生ヘッド位置 |
| 再生ヘッドより前をリップル削除（A） | 再生ヘッドがクリップ内にあるときのみ |
| 再生ヘッドより後ろをリップル削除（D） | 同上 |
| リップル削除（Delete） | 削除して後続を詰める |
| 削除のみ（空白を残す）（BackSpace） | 削除して、跡は空白のまま |
| レイヤー ▶ 最前面 / 前面 / 背面 / 最背面 | 重なり順の変更（V1 のクリップは最背面固定で対象外） |
| 使用する / 使用しない | 書き出しに含めるかの切り替え |
| カット頭へ揃える（字幕のみ） | 字幕の開始を V1 クリップ（カット）の頭へ揃える |
| すべての字幕をカット頭へ揃える | 全字幕を対象に実行 |
| ぼかし関連（V1 のクリップのみ） | 「このクリップをぼかす」／「このクリップのぼかしを消す」／「ぼかし...」 |
| 縦動画プロジェクトを作成（V1 のクリップのみ） | 9 章 |

### 5.4 右クリックメニュー（何もない所）

- ここへ再生ヘッドを移動
- 再生ヘッドへ貼り付け（Ctrl+V）
- 字幕トラックの空き領域なら: **字幕追加** ／ すべての字幕をカット頭へ揃える
  - 追加位置は編集点へ吸着します。コメント用トラック上で足した字幕は、最初から役割「コメント」になります。

### 5.5 右クリックメニュー（音声クリップ上）

- ミュート ／ ミュート解除
- 音量 ▶ +6 dB / +3 dB / 0 dB / -3 dB / -6 dB

※ 音声クリップには削除がありません（V1 側から消します）。

### 5.6 ズーム・スクロール

| 操作 | 説明 |
|---|---|
| －／＋ ボタン | 縮小・拡大（Ctrl + ホイールでも可） |
| 全体 ボタン | Timeline 全体が収まるまで縮小 |
| 横スクロールバー | 表示位置の移動 |
| 操作ヒント行 | 主要ショートカットを常時表示 |

キー割り当ては設定（`timeline.shortcuts`）で変更できます。

| D | 再生ヘッドより後ろをリップル削除 |
| Delete | リップル削除（設定 `ripple_delete` に従う。既定 = リップル削除） |

| BackSpace | 削除のみ（後続を詰めず空白を残す） |

| E | 倍速再生（トグル） |
| Q | 倍速逆再生（トグル・音声なし） |

| Home / End | 先頭へ / 末尾へ |
| Ctrl+C | コピー |
| Ctrl+V | 再生ヘッドへ貼り付け |
| Ctrl+Shift+A | 字幕の開始をカット頭へ揃える（字幕を選んでいればその字幕、選んでいなければ全字幕） |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Ctrl++ / Ctrl+= | 拡大 |

| Ctrl+S | 保存 |
| Ctrl+Shift+S | 名前を付けて保存 |
| G | 採点グラフの表示切替（切り抜き編集画面のみ） |
| Alt（押しながら） | ドラッグ中の吸着オフ |

## 7. 編集機能のふるまい（説明時の注意点）

| 機能 | 補足 |
|---|---|
| 分割 | 再生ヘッド位置、または右クリックした位置で切る |
| リップル削除 | 削除した尺のぶん後続が詰まる。詰める対象トラックは設定 `ripple_sync_tracks`（既定: 全トラック） |
| 削除のみ | 跡が空白として残る。空白は書き出し時に黒（設定 `render.gap_policy`） |
| リップルトリム（A / D） | 再生ヘッドがクリップ上にないときは実行されず、画面下に案内が出ます（エラーにはしません） |
| コピー＆ペースト | 貼り付け位置は再生ヘッド。干渉した既存ノードは右へずれ、ずれた秒数が案内に出ます。貼り付けられなかった件数も表示されます |
| 貼り付け失敗 | トラックのロック・素材の欠落が原因。その旨の案内が出ます |
| 字幕をカット頭へ揃える | V1 クリップの頭に合わせます。対象が無いときは「カット頭へ揃える字幕はありませんでした」 |
| Undo / Redo | 操作名付きで表示されます（例: 「元に戻す: クリップの移動」） |
| 最小クリップ長 | 0.05 秒（設定 `min_clip_sec`）。これより短くはトリムできません |
| 新規字幕の尺 | 2.0 秒（設定 `default_subtitle_sec`） |
| 画像の既定尺 | 5.0 秒（設定 `media.default_image_duration_sec`） |
| 追加できる素材 | 動画 `.mp4 .mov .avi .mkv .flv .wmv` ／ 画像 `.png .jpg .jpeg .bmp .gif .webp` |

## 9. 縦動画プロジェクトの作成

| 背景 | 分割時の背景の指定 |

## 11. DaVinci Resolve 出力

「DaVinci Resolve 出力」ボタンで、現在の Timeline を DaVinci Resolve 用プロジェクトファイル（`.fcpxml`）として出力します。
上書き確認・透かしの確認が入ります。

## 12. 書き出し（決定）

- 「決定」で Timeline の内容を反映した動画を書き出します。
- 映像クリップが 0 件のときは書き出せません（警告）。
- 「使用しない」にしたクリップ・字幕は書き出しから外れます。

## 13. 切り抜き編集（採点結果）画面の固有機能

Timeline 編集画面の全機能に加えて、上部にクリップバー、ドックに採点グラフが付きます。

| 項目 | 説明 |
|---|---|
| クリップ（コンボボックス） | 「clip1  0:00:10→0:01:20  点82.5」の形式で一覧。選ぶとその先頭へ再生ヘッドが飛びます |
| セクション追加... | 元動画の区間を指定してセクションを追加。元動画の時系列に沿った位置へ挿入され、既存セクションと重なる場合は 1 つに統合されます。準備中は進捗が出て中止もできます |
| このクリップを使用する | 外すと Timeline 上で灰色になり、書き出しから外れます（戻せます） |
| テーマ | 入力するとクリップ先頭にイントロカード、本編に左上タグが付きます。空欄 = テーマ演出なし |
| 採点グラフ（ボタン / G） | 採点グラフドックの表示切替 |
| 採点グラフ（ドック） | 時系列の採点カーブとクリップのマーカ。マーカをクリックするとその位置へ移動。上下左右へドッキング位置を変更できます |
| 完了（切り抜き＋字幕焼き込み） | 「決定」に相当するボタン |
