# 切り抜き自動編集（Stretheus）操作マニュアル

配信アーカイブから**フルテロップ入りの切り抜き動画**を作るアプリです。
やり方は 2 通りあります。

* **クリップ用** … 動画を 1 本選び、無音カット → テロップ生成 → 編集画面で確認 → 書き出し
* **アーカイブ切り抜き用** … 長い配信（Twitch VOD など）を自動で採点し、盛り上がった区間だけを
  切り抜いて 1 本にまとめる

対象OS: Windows 11 / 対象バージョン: v1.8.2

## 1. インストール

1. 配布サイトから **`StretheusSetup.exe`** をダウンロードします。
2. ダウンロードした `StretheusSetup.exe` をダブルクリックします。
3. 画面の案内に沿って進みます。途中で次の2点を選びます。
   - **編集した動画の出力先フォルダ** … 完成した動画を保存する場所を選びます（後から設定画面でも変更できます）。
   - **デスクトップにショートカットを作成する** … 必要ならチェックを入れます。
4. インストーラーが本体を自動でダウンロード・展開します。しばらく待つと完了します。

> **メモ**
> - インストールに管理者権限は不要です（ユーザーフォルダにインストールされます）。
> - 動画変換に必要な FFmpeg はアプリに同梱されているため、別途インストールは不要です。
> - インターネット接続が必要です（本体のダウンロードに使用します）。

## 2. メイン画面の見かた

- **デスクトップのショートカット**、または **スタートメニューの「Stretheus」** から起動します。
- 起動すると **「Stretheus」** というウィンドウが開きます。これがメイン画面です。

画面の上部にはタブが 2 つあります。

| タブ | 用途 |
|---|---|
| **クリップ用** | 動画 1 本を編集する（[4章](#4-クリップ用動画1本を編集する)） |
| **アーカイブ切り抜き用** | 長い配信を採点して切り抜く（[5章](#5-アーカイブ切り抜き用長い配信から切り抜く)） |

右上には次のものが並びます。

| 項目 | 役割 |
|---|---|
| 残高表示（「残り NNN pt」など） | 出力に使えるポイントの残りと次回リセット日。未ログインならこの端末ぶんの残高 |
| ログイン | Stretheus アカウントへログインします（[8章](#8-ログインとポイントサブスクリプション)） |
| サブスクリプション | 加入用の画面を開きます。加入済みならチェックマークが付きます |
| 表示言語 | 日本語 / English を切り替えます |
| 設定（歯車） | 設定画面を開きます |

### クリップ用タブの中身

| 項目 | 役割 |
|---|---|
| ドラッグ&ドロップ領域 | **動画ファイルをここへ放すと選べます**。「参照...」でも選べます |
| 参照... | 編集したい動画をファイル選択ダイアログから選びます |
| 続きから | 保存した Timeline プロジェクトを一覧から選んで編集を再開します |
| 実行（丸ボタン） | 編集処理を開始します |
| 進捗バー／ステータス | 処理の進み具合を表示します |

## 3. はじめに設定を確認する

初めて使うときは、右上の **歯車（設定）** を押して内容を確認しておきましょう。
設定画面は次のタブに分かれています。変更したら必ず下部の **「保存」** ボタンを押してください。

| タブ | 内容 |
|---|---|
| 一般 | 入出力フォルダ、オープニング／エンディング、無音カット、作業フォルダ、自動更新 |
| 字幕 | テロップの生成・文字色・フォント・改行・縁取り・位置など |
| 縦動画 | 縦（ショート）動画を作るときのキャンバスやテロップ配置 |
| アーカイブ | 切り抜きの採点・取得・イントロカード（テーマ演出）など |
| ぼかし | トラッキングぼかし（※設定で有効にしたときだけ表示されます） |
| アカウント | ログイン状態・ポイント残高・サブスクリプション状態と履歴 |

### まず確認したい項目

- **一般タブ → 出力ディレクトリ**
  完成した動画の保存先です。空欄の場合は「入力動画と同じ場所」に出力されます。
- **一般タブ → オープニング動画／エンディング動画**
  動画の前後に付けたい素材があれば「参照...」で選び、「**結合する**」にチェックを入れます。
- **一般タブ → 無音カットを有効にする**
  会話のない区間を自動で削るかどうかを選びます。既定はオンです。
- **字幕タブ → テロップ生成を有効にする**
  テロップ（字幕）を自動生成するかどうか。オフにするとその工程はスキップされます。
- **字幕タブ → 配信者カラー／サブカラー／コメントカラー**
  テロップの役割ごとの文字色です。編集画面で 1 本ずつ上書きもできます。

最初はほとんどの項目を初期値のままで問題ありません。

> **重要**: 設定を変更したら、画面下部の **「保存」** ボタンを押すまで反映されません。

## 4. クリップ用（動画1本を編集する）

1. 「クリップ用」タブで動画ファイルを指定します。
   - **ドラッグ&ドロップ**: 動画ファイルを画面中央の領域へ放します。**最も手軽です。**
   - **参照ボタン**: ファイル選択ダイアログから選びます。
   （対応形式: `.mp4` `.mov` `.avi` `.mkv` `.flv` `.wmv`）
2. **「実行」** ボタンを押します。
3. あとは画面の案内に沿って操作します。処理は次の順で進みます。

| 順 | 工程 | 画面に出るもの |
|---|---|---|
| 1 | 音声解析・正規化 | 進捗バー（YouTube 向けに音量をそろえます） |
| 2 | 音量解析 → **カット閾値の確認** | 確認ウィンドウ（下記 4-1） |
| 3 | 無音検出 | 進捗バー |
| 4 | 音声認識（文字起こし） | 進捗バー（長い動画では数分〜十数分かかります） |
| 5 | **Timeline 編集画面** | 編集ウィンドウ（[6章](#6-timeline-編集画面)） |
| 6 | 書き出し | 進捗バー → 完了メッセージ |

処理中はステータス欄にくるくる回るマーク（スピナー）が出ます。進捗バーが止まって見えても、
スピナーが回っていれば処理中です。

### 4-1. カット閾値の確認（音量解析）

無音カットの前に、アプリが動画の音量を解析し「**音量解析 — カット閾値の確認**」を表示します。
（「無音カットを有効にする」をオフにしている場合は表示されません。）

- **この dB（デシベル）以下を無音としてカット**し、それ以上を残します。
- 表示された数値は目安です。必要なら手で修正できます。
  - **もっと多くカットしたい** → 数値を **大きく**（例: −28 → −24）
  - **カットしすぎる／会話が切れる** → 数値を **小さく**（例: −28 → −32）
- **「OK」** … その値でカットします（値は次回以降の初期値として保存されます）。
- **「変更しない」** … 保存済みの値のまま処理を続けます（中断ではありません）。

> **補足**: 設定で「無音カット」を従来方式（実際に動画を切る方式）にしている場合は、
> Timeline 編集画面ではなく**字幕一覧画面**（テロップを表で直す画面）が開きます。
> 既定は Timeline 編集画面です。

## 5. アーカイブ切り抜き用（長い配信から切り抜く）

「アーカイブ切り抜き用」タブを開きます。

### 5-1. 入力を決める

| 入力ソース | 手順 |
|---|---|
| **ローカル動画** | 動画ファイルをドラッグ&ドロップ、または「参照...」で選びます。任意で**コメントJSON**を指定するとコメントも採点に使われます |
| **Twitch VOD** | 「Twitch ログイン」を押してブラウザで許可すると、**自分の VOD** が一覧に出ます。選ぶとアプリが動画とコメントを自動で取得します |

> Twitch VOD は**自分が所有する配信のみ**が対象です（他人の配信は切り抜けません）。
> ログインし直すと、配信中に付けた**ストリームマーカー**も採点に使えます
> （マーカーの前後は「必ず残す区間」になります）。

### 5-2. 採点して切り抜く

1. 必要なら「無音カット」のチェックを確認します。
2. **「採点開始」** を押します。進捗は「VOD取得中…」→「採点中…」→「文字起こし中…」と進みます。
   途中でやめたいときは **「中止」** を押します。
3. 採点が終わると **切り抜き編集（採点結果）画面** が開きます。ここで全クリップをまとめて確認します。

| 項目 | できること |
|---|---|
| クリップ（コンボボックス） | 「clip1 0:00:10→0:01:20 点82.5」の形式で候補を切り替えます |
| 採点グラフ | 時系列の採点カーブ。マーカをクリックするとその位置へ移動します（`G` で表示切替） |
| このクリップを使用する | 外すと書き出しから除かれます |
| テーマ | 入力するとクリップ先頭に**イントロカード**、本編に左上タグが付きます。空欄なら演出なし |
| セクション追加... | 元動画の区間を指定して候補を足せます（必要な区間だけ取り直します） |
| 字幕・Timeline の編集 | [6章](#6-timeline-編集画面)と同じ操作ができます |
| 完了（切り抜き＋字幕焼き込み） | 書き出しを開始します |

4. 書き出しが終わると、クリップごとのファイルと、設定で結合が有効なら**まとめた 1 本**が出力されます。

> **取得した配信データの削除**: 取得した VOD は容量が大きい（1 本 10〜25GB）ため、
> 既定では不要になった時点でゴミ箱へ送られます。タブの「取得データを削除」からも
> まとめて回収できます。

## 6. Timeline 編集画面

動画編集ソフトのような画面で、カット・テロップ・素材を確認して直せます。
機能の一覧は **`docs/howto/timeline_features.md`（同内容の HTML 版あり）** にまとまっています。
ここでは最低限だけ説明します。

- 上段が**プレビュー**、下段が**Timeline**（トラックの並び）です。
- プレビュー上でテロップや画像を**ドラッグ**すると位置を動かせます。
- Timeline のクリップを右クリックすると、分割・削除・使用しない・ぼかし・縦動画プロジェクト作成などが出ます。
- テロップをクリックすると、右側で**文章・役割（配信者/サブ/コメント）・フォント・サイズ・色**を直せます。
- よく使うキー: `Space` 再生/停止、`W` 分割、`Delete` 削除（後ろを詰める）、
  `Ctrl+Z` 元に戻す、`Ctrl+S` 保存、`Ctrl+Shift+A` テロップをカット頭へ揃える。
- 下部の「元に戻す」の左にある **「？」** ボタンで、取り扱い説明の画像を開けます。

下部のボタン:

| ボタン | 動作 |
|---|---|
| 元に戻す / やり直す | 直前の編集の取り消し・やり直し |
| 保存 / 名前を付けて保存 | 編集内容をプロジェクトファイルへ保存します（後から再開できます） |
| DaVinci Resolve 出力 | 現在の内容を `.fcpxml` として出力します（別ソフトで仕上げる場合） |
| **決定** | この内容で動画を書き出します（誤操作防止のため Enter/Space では動きません） |
| キャンセル | 編集を破棄して処理を中断します（動画は出力されません） |

## 7. 編集の続き（保存したプロジェクトを開く）

Timeline 編集画面で「保存」したプロジェクトは、後から開き直して書き出せます。

1. メイン画面のタブで **「続きから」** を押します（クリップ用／アーカイブ切り抜き用でそれぞれ分かれています）。
2. 一覧から選ぶか、ファイルを直接指定します。
3. 保存していない編集が自動保存に残っている場合は、復元するか聞かれます。
4. 素材が見つからないときは、**作り直す**か**差し替え（再リンク）**を案内します。
5. Timeline 編集画面が開くので、直して「決定」を押せば書き出されます。

> アーカイブ切り抜き用のプロジェクトは「アーカイブ切り抜き用」タブの「続きから」で開いてください
> （クリップ用から開こうとすると案内が出ます）。

## 8. ログインとポイント・サブスクリプション

- 出力（書き出し・Resolve 出力）1 回につき**ポイントを消費**します。
- **未ログインでも使えます**。そのあいだはこの端末ぶんのポイントを消費します。
  ログインすると、アカウントのポイントを端末をまたいで使えます。
- ログインは **Twitch** または **Google** から選べます（右上の「ログイン」またはサブスクリプション画面）。
- 残高が足りない場合は**透かし入りでの出力**になります。
  その場合は書き出しの前に確認が出るので、やめることもできます（やめればポイントは消費しません）。
- **サブスクリプション**に加入すると、ポイントを消費せず透かしの入らない出力が無制限になります。
  右上の「サブスクリプション」から ①ログイン → ②購入 → ③反映待ち の順に進みます。
  支払いは Stripe の画面で行い、アプリがカード情報を扱うことはありません。
- 残高・履歴・加入状態は **設定画面の「アカウント」タブ**でも確認できます。

> サーバーへ接続できないときは、最後に取得した残高を表示します。
> ログインやポイントの確認ができなくても、**編集と書き出しは続けられます**。

## 9. 出来上がった動画の確認

- 完成した動画は、設定画面で指定した **出力ディレクトリ** に保存されます（未指定の場合は入力動画と同じ場所）。
- クリップ用のファイル名は `<元の名前>_edited.mp4` です。
  アーカイブ切り抜きは `archive_<元の名前>_clip<番号>_<開始>-<終了>.mp4` と、結合した 1 本が出ます。
- 同じ名前のファイルがある場合は、上書きされないようにファイル名が自動調整されます。
- 完了メッセージに表示されるパスが、実際の保存先です。

## 10. 設定項目の説明

設定画面（右上の歯車）にある項目の意味です。よく使う項目を中心に説明します。

### 一般タブ

| 項目 | 説明 |
|---|---|
| 動画ディレクトリ | 動画をまとめて置いている既定フォルダ。「参照...」の初期表示に使われます |
| オープニング動画 / エンディング動画 | 本編の前後に結合する動画。「結合する」にチェックした場合のみ使われます |
| 出力ディレクトリ | 完成動画の保存先。空欄なら入力動画と同じ場所へ出力します |
| 作業フォルダ | 処理中の一時ファイルを置く場所。空欄なら Windows の一時フォルダを使います |
| 開始前に必要な空き容量(GB) | この空きが無ければ処理を始めません（0 で確認しない） |
| 自動更新（起動時に更新を確認する） | 起動時に新しいバージョンを確認します（[12章](#12-アプリの更新について)） |
| 無音カットを有効にする | 会話のない区間を自動で削るかどうか。※オフのときはカット閾値の確認画面も出ません |
| フェード / フェード時間(秒) | 無音カットのつなぎ目に軽いフェードを付けるかどうかと、その長さ |

### 字幕タブ

| 項目 | 説明 |
|---|---|
| テロップ生成を有効にする | テロップ（字幕）を作るかどうか |
| 焼き込み前に字幕編集画面を開く | 従来方式のときに、テロップを表で確認・修正します |
| 発話区間のみテロップを表示する / 発話最小無音長 / 絞り込み方式 / 前後パディング | 声のある区間だけにテロップを絞り込むための設定 |
| 実行デバイス / 計算精度 | 音声認識の実行環境（CPU）と精度（通常は `int8` のまま） |
| 字幕言語 | 認識する言語（`ja` 日本語 / `en` 英語） |
| 配信者カラー / サブカラー / コメントカラー | 役割ごとのテロップ文字色。色ボタンから選べます |
| フォントの大きさ / フォント種類 | テロップの文字サイズとフォント |
| 改行方式 / 1行下限文字数 / 1行最大文字数 | 「BudouX(文節)」＝読みやすい位置で改行、「文字数」＝指定文字数で改行 |
| アウトラインカラー / アウトラインの太さ / 背景・影の色 | テロップの縁取りと背景 |
| 装飾（太字／斜体／下線／打消し線）/ 文字間隔 / 回転角度 | 文字の見た目 |
| 縁取りスタイル / 表示位置 / 余白（左・右・下） | テロップの描き方と画面内の位置 |

### 縦動画タブ

縦（YouTube ショート / TikTok 向け）プロジェクトを作るときの、キャンバス寸法・
テロップの大きさと位置・切り抜きの背景などを設定します。

### アーカイブタブ

| 項目 | 説明 |
|---|---|
| 切り抜き候補の件数・窓の長さ | 採点でいくつの区間をどれくらいの長さで選ぶか |
| 採点の重み（感情／コメント） | 盛り上がりの判断に音声とコメントをどの比重で使うか |
| ストリームマーカー | 配信中のマーカーの前後を必ず残す長さ |
| イントロカード（テーマ演出） | 開始前バッファ・ぼかし・黒帯・タイトル文字・タグの見た目 |
| 結合 | クリップを 1 本にまとめるか、個別も残すか |

### アカウントタブ

ログイン状態・ポイント残高・ポイント履歴・サブスクリプションの状態と履歴を表示し、
ログイン／ログアウト、サブスクリプションの管理ができます。

> **色の入力形式について**
> - 配信者／サブ／コメントカラー: `#RRGGBB` 形式（例: `#ED0004`）
> - アウトライン・背景色: 透明度付きの `&HAABBGGRR` 形式
> いずれも横の色ボタンを押せばカラーピッカーで選べるので、形式を意識せず設定できます。

設定を変えたら、画面下部の **「保存」** を押すのを忘れないでください。

## 11. 困ったときは（トラブルシューティング）

| 症状 | 対処 |
|---|---|
| 「存在する入力動画を指定してください」と出る | 動画を選び直してください。ファイルが移動・削除されていないか確認します |
| ドラッグ&ドロップで動画が入らない | 対応形式（`.mp4` `.mov` `.avi` `.mkv` `.flv` `.wmv`）を1つだけ放してください。処理中はドロップを受け付けません |
| 「この動画を読み込めません」と出る | 動画が壊れている／0 バイトの可能性があります。別の動画で試してください |
| 「空き容量が足りません」と出る | 出力先・作業フォルダのドライブを空けるか、一般タブの必要空き容量を見直します |
| 無音カットしたくない（テロップだけ作りたい） | 一般タブの「無音カットを有効にする」のチェックを外して保存します |
| テロップが作られない | 字幕タブの「テロップ生成を有効にする」がオンか確認します |
| 無音が削られすぎる／会話が切れる | カット閾値の確認画面で dB を **小さく**（例: −32）します |
| 無音が残る | カット閾値の確認画面で dB を **大きく**（例: −24）します |
| テロップの誤変換が多い | Timeline 編集画面（または字幕一覧画面）で文章を直接修正できます |
| Twitch VOD が一覧に出ない | 「Twitch ログイン」を押し直してください。**自分が所有する VOD のみ**対象です |
| VOD の取得に失敗する | 画質が見つからない場合があります。設定の画質フォールバックを有効にして再試行します |
| 出力に透かしが入る | ポイント残高が足りていません。[8章](#8-ログインとポイントサブスクリプション)を参照してください |
| 処理が止まって見える | スピナーが回っていれば処理中です。特に音声認識は時間がかかります |
| エラーで停止した | 表示されたメッセージを確認してください。詳しい記録は `logs` フォルダのログに残ります |
| 処理を途中でやめたい | Timeline 編集画面の「キャンセル」、アーカイブ採点中は「中止」を押します |
| 編集をやり直したい | 保存しておけば「続きから」で再開できます（[7章](#7-編集の続き保存したプロジェクトを開く)） |

## 12. アプリの更新について

- 一般タブの「**起動時に更新を確認する**」がオンの場合、起動時に新しいバージョンがあるか自動でチェックします。
- 新しいバージョンが見つかると「更新の確認」ダイアログが表示されます。
  - **「はい」** … 更新プログラムをダウンロードして自動で適用します（更新中はアプリが再起動されます）。
  - **「いいえ」** … 更新せずにそのまま使います。
- 更新しても、これまでに設定した内容（出力先や字幕の設定など）は引き継がれます。
- 更新の確認を無効にしたい場合は、一般タブの「起動時に更新を確認する」のチェックを外して保存してください。

テロップの見え方を確認しながら、設定を自分好みに調整していくのがおすすめです。
