# Request
StretheusのTimeline画面でテロップと発話のタイミングがずれている原因を教えてください。
発話のタイミングで映像＆音はカットがいい感じに切れていますが、その先頭にテロップが表示されてほしいのに、基本的にそのカットの前からテロップが流れています。
毎回この発話とテロップの位置調整を行っているので、すごく面倒です。発話のカットの先頭とテロップの先頭がぴったり同じ時間にあるのが好ましい。
ソースを解析して修正設計書を出力してください。
