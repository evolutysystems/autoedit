# Split Sound概要
AIを使用し、自動編集パイプラインを行う前に、話者の声とその他の音（ゲーム・環境音）を分ける。（音声分離）
分けた音声を使用して既存の自動編集パイプラインを行う。
完成した動画には音声分離をしていない元々の音声を使用する（パイプラインの仕様上、音量の正規化はされているもの）

## 使用AI
AIは以下を使用し、検証を行う。
- Demucs(htdemucs)
- DeepFilterNet(DF3)

## 求める結果
- 無音カット（配信者が話している個所だけカット）、文字起こしの精度の向上
- AIを使用することによる、処理時間の増加(既存処理との比較)
