# Request
サブスクリプションを登録する画面が設定画面にあるので、これをmain_window.pyの設定ボタンの左に配置してください。
サブスクリプション画面を新規で作成してください。
そこにはTwitchのLoginボタンと、購入ボタンを配置してください。
①TwitchのLoginボタンを押して、ログインしたアカウントがtwitchのtatsumicをサブスクリプションしている場合であれば、購入ボタンを押せないようにしてください。
　①が完了しmain_windowに戻ってきた際には、サブスクリプションボタンが押せないようになっており、文言の部分にチェックマークを記載してください。Twitchログインの場合はチェックマークの色は「#9147FF」です。
②購入ボタンを押下して、既存のサブスク処理を走らせてください。
　②が完了しmain_windowに戻ってきた際には、サブスクリプションボタンが押せないようになっており、文言の部分にチェックマークを記載してください。
設定画面のアカウントタブにはサブスク状態と、履歴を表示してください。

# Output
resolve2.mdとして修正設計書を出力してください。
