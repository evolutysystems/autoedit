# Request19
以下の機能を「アーカイブ切り抜き用」のみ適応してください。
- 字幕一覧画面の上部にテキストボックスを追加する。
- placeholderで「(任意)テーマを決めてください」と記載
- このテキストボックスになにも記載していなければなにもしない。
- 記載されていれば以下を実行する。
　・そのクリップが開始される前の1.5秒分をバッファとして増やす（切り抜いていると思うので戻す）
　・1.5秒間で以下を実行する。
　　画面全体をブラーする。
　　横幅一杯、縦は上部と下部に余白をそれぞれ300px残した黒色要素を、ブラーをかけた上に乗せる。
　　画面中央に先ほどテキストボックスで記載した内容を表示する。
　　1.5秒経つとブラーと要素、テキストボックスに書いた内容が消える。
　　テキストボックスの内容は、そのクリップの間は左上に小さく記載する。
