# Request
ボカシ処理に関して、もっとシンプルでいい気がしてきました。
①選択したクリップに対して、ボカシ処理ウィンドウを開く。
②キャンバス（動画内）をマウス等で囲む。
③囲んだ場所をトラッキングするように設定する。
④一番最初に囲った場所に対して、以下のダイアログを出すようにする。
　指定した場所をどうしますか？
　ボカす　　ボカさない
⑤④で「ボカす」を選択した場合は、マウスで囲った場所をボカす。
⑥④で「ボカさない」を選択した場合は画面全体がボカされ、マウスで囲った場所のみボカさない。
　その後、ボカすを選択してさらに指定場所を増やした場合はボカし、ボカさないを選択した場合は、指定した場所をボカさない動きを行う。
⑦ボカシ処理ウィンドウ内では、方向キーで動画をコマ送りすることができる。
⑧マウスで囲った指定場所は動かすことができる。
⑨トラッキングがうまくできない場合があると思うので、コマ送りして手作業で動かした場合、そこにキーフレームを打ち、動かした場所に指定場所を移動させる。
⑩指定場所は拡大、縮小ができる
そしてこれらをクリップ内でのみ行う。
現状のボカし処理を大幅に変更してシンプルにしたい。
