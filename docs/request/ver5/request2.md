# Request
人物・建物検出によるトラッキングぼかし機能を実装したいです。

## 機能の有効化
設定画面からトラッキングぼかし機能を使用するかを決定します。

## 人物の判定方法
人物の場合は顔で判断するのではなく、服装を含めた身体全体で判断するようにします。

## 人物の指定方法
- 動画全体で一番映っている人物はぼかしをかけない。
- ぼかし機能をオンにした状態で Timeline 画面が開かれると、ぼかし指定画面が開けるようになる。
  その画面の機能は以下。
  - ぼかしをかける・かけないの指定を、パスで囲うようにして指定することができる。
  - 指定後、Timeline 上の全てのセクションを見直して、指定した部分が該当していれば
    すべてにぼかしをかける・かけないの対応を行う。
