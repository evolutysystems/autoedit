# Request

横動画から縦動画 (YouTube Shorts 用) のプロジェクトを作れるようにしたい。

① 横動画 (1920x1080) の編集中に、Timeline 上でクリップを選ぶ。
② 右クリックから「縦動画プロジェクトを作成…」を開く。
③ ダイアログでソースのどこを切り抜くかを決める。
　・全体 … 枠 1 つ。切り抜いた絵を縦キャンバスへ置き、余った上下は背景で埋める。
　・分割 … 枠 2 つ。上下に積んで縦キャンバスをぴったり埋める (Twitch 的な構図)。
④ 枠はマウスで移動・拡大縮小できる。右側に縦の仕上がりを出す。
⑤「作成」で、選んだクリップだけを詰めた**縦のクリップ用プロジェクト**を書き出す。
⑥ 書き出したプロジェクトは「クリップ用」タブの「続きから」でそのまま開けること。
⑦ 既存の横プロジェクトの出力は 1 バイトも変わらないこと。

上位計画は `D:/develop/StretheusPlan/plan.md` の **P3「横動画から縦動画プロジェクトを作成」**。
