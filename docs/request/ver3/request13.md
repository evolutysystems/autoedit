# Rquest
アーカイブ用のTimeline編集画面にセクションの追加機能が欲しいです。
現状は採点方式によるセクション選定を行っていますが、そこは変更しなくていいです。
ただ、動画編集において他のセクションが必要になる場面があるので、それができる機能が欲しい。
セクション追加時には以下の動作を行ってください。
- セクションを指定して追加した場合、TimeLine上には、その指定したセクションが元動画の時系列として正しい位置に挿入してください。
　・どのセクションよりも先頭であればTimeLineの先頭に挿入する。
　・どのセクションよりも後ろであれば最後に挿入する。
　・セクションとセクションの間であれば、既に配置しているTimelineのセクションの間に挿入する。
- セクションを追加した際に、そのセクションに対して字幕等の処理は全て行う。
- セクションを追加した際に既存のTimelinのセクションと被っていれば、マージする。
