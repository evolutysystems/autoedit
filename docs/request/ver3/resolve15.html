3部品の修正 — チェックボックス（D2）

現行 — 塗りだけで印が無い

無音カット コメント採点を使う QCheckBox::indicator:checked は背景と枠の色を変えるだけ。 ::indicator へ QSS を当てた時点で Qt は既定の印を描かなくなる。
状態実測（左 20×24px の色）
チェック済み#E8A15C 236 px / #1B1B1F 0 px

修正後 — 塗りの上にチェックマーク

無音カット コメント採点を使う 印を accent.on（アクセントの上に載せる文字色）で描いた PNG を作り、 image: で載せる。枠・角丸・大きさ（14px / 3px）は現行のまま。
状態実測（同じ範囲）
チェック済み#E8A15C 184 px / #1B1B1F 14 px（＋中間色）

5部品の修正 — 設定ボタンの下余白（D1）

現行 — ペインに接している

setCornerWidget はタブバーの高さいっぱいにボタンを置くため、 下辺がペインの上辺へ接する。QSS では余白を作れない。

修正後 — 下に 6px の余白

余白付きの入れ物で包んでからコーナーへ渡す（theme.install_tab_corner）。 余白 6px は Qt のレイアウト既定間隔と同じ値。

3〜5 は QSS の共通部分のため、アプリ全体（設定画面・Timeline 編集画面・ アーカイブ用タブ・字幕編集画面）へ同時に効く。 大きさと位置は変わらないため、各画面のレイアウトは崩れない（resolve15 §8）。
表の実測値は QT_QPA_PLATFORM=offscreen / ui.theme_mode=dark で ウィジェットを grab() して色を数えたもの（resolve15 §2.2 / §2.3）。
