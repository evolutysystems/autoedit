# Request

以下の要望がある。

・**Timeline 上のノード全て**に対して、以下の動作ができるようにしてほしい。

  1. **Ctrl+C** で選択状態のノードをコピーする。
  2. **Ctrl+V** で、**再生ヘッダー（再生ヘッド）が示している箇所**にコピーしたノードを貼り付ける。
  3. Ctrl+V で貼り付けた際に、**すでに存在しているノードと被りそうな場合**は、
     **すでに存在しているノードが優先**され、**貼り付けたノードが短縮される**。
  4. **Ctrl+V はただの貼り付け**で、**Ctrl+Shift+V の場合は貼り付けるノードが優先**されるため、
     **貼り付けた分だけ Timeline が右にズレる・伸びる**イメージ。

# Output

・本ファイル（`docs/request/ver3/request10.md`）を要望として出力する。
・`docs/request/ver3/resolve10.md` として修正設計書を出力する。

# Request（追加 / rev2 — 2026-08-21）

・**Ctrl+V の動作を、すべて Ctrl+Shift+V の動作（貼り付けたノードが優先され、
　既存ノードが右へズレる）に置き換える。**
　→ **Ctrl+Shift+V のショートカットキーは無くす**（必要なのは割り込みの動作だけのため）。

・ただし、**右へズレるのは「そのトラック上だけ」の話**。

  例：
  - V1 に動画があり、V1 の最初の方に動画を貼り付ける
    → **V1 上のノードが右へズレていく**（これは意図どおり）。
  - 画像を V2 トラックに置き、その画像をコピーして貼り付ける
    → **V2 上の他ノードに干渉しない場合は、そのまま貼り付ける**
    　（他ノードも他トラックも動かさない）。

・**補足（rev2-a）**: ただし **V1 に関しては S1（字幕）も一緒にズレる**ようにする。
　V1 だけを右へズラすと、V1 の映像に合わせて作った字幕が置いていかれてしまうため。
　（V2 以降へ貼る場合は上記のとおり、そのトラックだけの話とする。）
