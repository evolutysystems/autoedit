# ver12 request3 — アーカイブ切り抜き用タブのデザインをクリップ用に揃える

要望 (2026-11-18 / 利用者):

> Main＿Window.py のアーカイブ用切り抜きタブ内のコントロール達のデザインを変更したいです。要望は以下。
> ・ベースのデザインをクリップ用と同じにする。ドラッグ＆ドロップエリア、実行ボタン等。
> ・現在 Twitch のログインステータスがタブ内に表示されていると思うがこれを削除する。
> ・もし Twitch にログインしていれば URL を貼るようにテキストボックスがドラッグ＆ドロップエリアの上部に出現する。

---

## 1. 要望の整理

| # | 求めていること | 受け入れ条件 |
| --- | --- | --- |
| **A** | アーカイブ切り抜き用タブの**ベースのデザインをクリップ用タブと同じにする** | D&D 領域 (上部・画面の主役) → 「続きから」→ 実行ボタン (▶ / 中央・幅 96px) → 進捗バー → 状態ラベル、の並びと見た目が両タブで一致する |
| **B** | **Twitch のログインステータス表示を削除する** | 「ログイン中: {名前}」「未ログイン」などの常設ラベルがタブ内から無くなる |
| **C** | **ログイン済みのときだけ** URL 貼り付け用のテキストボックスが **D&D 領域の上部**に出る | 未ログインでは出ない。出た欄に VOD の URL を貼って実行できる |

## 2. 現状 (2026-11-18 / main)

* 画面を作っているのは `src/gui/archive_tab.py` の `ArchiveTabWidget._build_ui`
  (`main_window.py` はこのタブを `addTab` するだけ。要望文の「Main＿Window.py の
  アーカイブ用切り抜きタブ」= このウィジェット)。
* クリップ用タブ (`main_window.py` の `ClipTabWidget._build_ui`) は
  ver3 resolve15 で **D&D 領域 + 中央の 2 ボタン**へ作り替えてあり、
  アーカイブ用タブだけが**それ以前の形 (説明文 + 入力ソースのプルダウン +
  2 本のパス欄 + 「編集の続き」行)** のまま残っている。
* アーカイブ用タブが今持っている部品:
  説明ラベル / 入力ソース選択 (ローカル・Twitch) / 入力パス欄 + 参照... /
  コメントJSON 欄 + 参照... / **Twitch ログインボタン + ログイン状態ラベル** /
  自分の VOD プルダウン / VOD URL 欄 / 無音カットのチェック /
  採点開始 + 中止 / 「編集の続き」行 (`ProjectResumeRow`) /
  取得データの使用量 + 削除ボタン / 進捗バー + 状態ラベル。
* D&D 領域の部品 `FileDropArea` は**種別を知らない作り**で、
  「アーカイブ切り抜き用タブへもそのまま載せられる」ことが
  設計時 (ver3 resolve15 §11 F1) に意図されている。
* アーカイブ用タブは今 `setAcceptDrops` を持たず、**ファイルを落として選べない**
  (`MainWindow` は現在のタブへドロップを回すが、受け口が無いため無視される)。
