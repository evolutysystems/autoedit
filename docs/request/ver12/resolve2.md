## 0. 先に結論

**5 種すべて実装できる。ただし 3 点、仕様を決め切らないと「できたが使えない」ものになる。**

| # | 決め切りたい点 | 本書の案 |
| --- | --- | --- |
| ① | **「単語」をどう切るか** | 認識由来のテロップは `origin["words"]` の単語時刻をそのまま使う。本文を手直し済み・手入力のテロップは **BudouX で句に切り、尺を文字数で按分**する (近似) |
| ② | **「重要語句」を誰が決めるか** | **自動判定はしない**。設定のキーワード一覧 + テロップ 1 本ごとの「強調する語」欄で決める |
| ③ | **編集画面のプレビューでも動かすか** | 動かす。ただし**アニメ付きのテロップだけ**毎フレーム描き直す。重い環境では設定で切れる (切ると「動き終わった状態」を静止表示) |

出力 (ASS) 側は既存の `build_subtitle_file` の中で完結し、**アニメ指定の無いテロップの
ASS は 1 文字も変わらない**。

## 1. 可否の判断 (要望への回答)

| アニメ | 出力 (ASS) の実現方法 | プレビュー (Qt) | 判定 |
| --- | --- | --- | --- |
| **Fade In / Fade Out** | `\fad(in_ms,out_ms)` を 1 つ足すだけ | 不透明度を時刻で変える | **容易**。コメントの背景・縁・影も一緒にフェードする |
| **Big Word** | 単語ごとに `{\an5\pos(中央)\fs大}` のイベントを 1 本ずつ出す | 中央に 1 語だけ大きく描く | **容易**。ただし元のテロップの位置・文字寄せ・折り返しは**無効になる** (画面中央の 1 語に置き換わるため) |
| **Word Pop** | 単語ごとに `{\pos(語の位置)\t(0,T1,\fscx130\fscy130)\t(T1,T2,\fscx100\fscy100)}` のイベントを出す。単語の位置は `font_advance` の実測送り幅で求める | 単語ごとのパスを拡大率付きで描く | **可能**。精度は ① の単語区切りに依存する |
| **Bounce** | 単語ごとに `\move` を 3 段 (大きく跳ねる → 小さく跳ねる → 収まる) + 保持 1 本 = 4 イベント。バネの減衰は段の振幅で表す | 単語ごとに Y オフセットを与える | **可能**。ただし**イベント数が単語 x 4 に増える** (§9 で上限と退避口を用意) |
| **重要語句の強調色** | 該当語のイベントだけ `\c&H…&` と `\fs` を足す | 同じ色で描く | **可能**。ただし ② の「誰が決めるか」が要る |

### 判定の根拠 (同梱 FFmpeg / libass での実測 2026-11-18)

要望の 5 種を表す ASS を手で書き、同梱 FFmpeg (libass) で 640x360 の黒画面へ焼いて
フレームを測った。**「書けるはず」ではなく、実際に出た絵で確かめている。**

| 確認したタグ | 測り方 | 結果 |
| --- | --- | --- |
| `\fad(300,300)` | 時刻ごとの白画素数 | 0.02s = **0 px** (透明) → 0.5s = 804 px (表示)。フェードが効く |
| `\pos` + `\t(0,80,\fscx130\fscy130)` → `\t(80,200,\fscx100\fscy100)` | 1 語目の面積 | 601 → 815 → **1052** (頂点) → 886 → **601** (元に戻る)。「拡大して元のサイズに戻る」が出る |
| 単語ごとの独立イベント | 文字の重心 x | 1 語目だけ (x=198) → 2 語目追加後 (x=268)。**先の語は動かない** (行が組み直されない) |
| `\c&HFFD34D&` + `\fs52` (強調語) | 画素と重心 | 2 語目が別色・別サイズで同時表示される |
| `\move(200,300,200,220,0,200)` を段に分けたイベント | 文字の重心 y | 2.18s = **y218.7** → 2.5s = **y298.8**。80 px の上下動が出る (バネの段組みに使える) |
| `\an5\pos(320,180)\fs104` (Big Word) | 画素数 | 3,893 px (通常 601 px の約 6.5 倍) が中央に出る |

### 技術的にできないこと (代案で回すもの)

| できないこと | 理由 | 代案 |
| --- | --- | --- |
| 1 イベントの中で「位置」を多段に動かす | ASS の `\t` が動かせるのは色・大きさ・回転・透明度などで、**位置 (`\pos`) は動かせない**。位置は `\move` の 2 点間 1 回だけ | Bounce は段ごとにイベントを分ける (上記) |
| 1 つのテロップの中で一部の語だけ拡大する | 行の中で文字を拡大すると**後続の文字が押し出されて行全体が揺れる** | 単語ごとに `\pos` を持つ独立イベントにして、行を組み直さない |
| コメント役割 (背景の箱 + アイコン) に Word Pop / Bounce / Big Word | 箱は本文の寸法から作る別イベント、アイコンは ffmpeg の overlay で、**単語ごとの位置には追従できない** | コメントは **Fade In / Out のみ**対応。他を選んだら警告してフェードへ落とす |
| DaVinci Resolve 出力 (FCPXML) への反映 | `<caption>` / `<title>` に単語ごとの動きを書く仕様が無い | 書き出し前に「アニメーションは引き継がれません」と知らせる (SE と同じ扱い / ver12 resolve1 §16) |

## 2. 決め切る 3 点

### 2.1 ① 単語の切り方

| 条件 | 切り方 | 精度 |
| --- | --- | --- |
| 認識由来で、本文が未編集 (`origin["words"]` の連結と本文が一致) | **単語時刻をそのまま使う** | 発話どおり = 要望の「発言した単語が 1 つずつ」 |
| 本文を手直し済み / 手入力 / 旧プロジェクト | **BudouX で句に切り、表示尺を文字数で按分** | 見た目は自然。時刻は発話と厳密には一致しない |
| BudouX が無い環境 | 句読点と空白で切り、同じく按分 | 粗い |

* 一致判定と「先頭語からの相対時刻」の求め方は、既存の分割処理
  (`commands._char_index_from_words`) と**同じ規約**を使う。`origin["words"]` は
  素材時間なので、`単語の開始 - 先頭語の開始` をテロップ開始からの相対秒として扱う。
* 切った結果は 1 か所 (`subtitle_animation.split_words`) にまとめ、
  出力・プレビューの両方が同じ列を見る (ずれると「プレビューと出力が違う」になる)。

### 2.2 ② 重要語句の決め方

**自動判定はしない** (「重要」の根拠になるデータが無い。認識の確信度は
「聞き取れたか」であって「重要か」ではない)。2 つの入り口を用意する。

| 入り口 | 置き場 | 使いどころ |
| --- | --- | --- |
| **設定のキーワード一覧** | `subtitle.animation.emphasis_words` (配列) | 毎回強調したい語 (チャンネル名・決め台詞など) |
| **テロップ 1 本ごとの「強調する語」** | `SubtitleClip.emphasis` (読点区切りの文字列) | その回だけ強調したい語 |

* 一致は**部分一致** (単語がキーワードを含む / キーワードが単語を含む) で判定する。
  日本語の単語区切りは認識任せなので、完全一致だけでは当たらない。
* 強調の見せ方は設定で決める: 色 (`emphasis_color`) と拡大率 (`emphasis_scale`)。
* 本文へ記号を埋め込む方式 (`[[語]]` など) は採らない。**本文が記号ごと焼き込まれる
  事故**が起きるため (アニメを後から OFF にした場合・旧版で開いた場合)。

### 2.3 ③ プレビューでの再現

現状のプレビューは「時刻では字幕を描き直さない」(ver8 resolve8 §9-3)。
これはタイル完成のたびに作り直すとチカチカする・重いという理由で、
**意図して**そうしてある。アニメを入れるとここに触ることになる。

| 方式 | 内容 | 採否 |
| --- | --- | --- |
| A | アニメ付きのテロップだけ、再生ヘッドが動くたびに**描き直す** (作り直しではなく `paint` だけやり直す) | **採用**。単語ごとのパスは 1 回作って使い回し、paint 時に変形だけ掛ける |
| B | プレビューでは動かさず「動き終わった状態」を出す。動きの確認はプロキシ再生で行う | 退避口として設定で選べるようにする (`preview_animation: false`) |
| C | 毎フレーム作り直す (素直な実装) | **不採用**。縁の作り直しが入るため、軽量化の方針に逆行する |

* 作り直し判定の署名 (`_overlay_signature`) に、**アニメ付きクリップのときだけ**
  時刻成分を足す。アニメ無しのテロップは現状と完全に同じ (描き直さない)。
* Big Word はプレビューでも中央 1 語に置き換える (位置ドラッグは無効にする)。

## 4. R1 データモデル

```python
# アニメーションの種類 (ver12 resolve2 §4)
ANIM_NONE = ""
ANIM_WORD_POP = "word_pop"
ANIM_BOUNCE = "bounce"
ANIM_BIG_WORD = "big_word"
SUBTITLE_ANIMATIONS = (ANIM_WORD_POP, ANIM_BOUNCE, ANIM_BIG_WORD)
```

`SubtitleClip` へ 4 つ足す (すべて既定値 = 従来と同一の出力)。

| 項目 | 型 | 意味 |
| --- | --- | --- |
| `animation` | str | `""` / `word_pop` / `bounce` / `big_word` |
| `fade_in` | bool | 表示のはじめにフェードイン |
| `fade_out` | bool | 表示の終わりにフェードアウト |
| `emphasis` | str | 強調する語 (読点・カンマ区切り)。Word Pop でのみ使う |

* **フェードは種類と独立**にする。要望では 5 つが並んでいるが、
  「Word Pop しながらフェードインしたい」が自然に出てくるため、
  `animation` コンボ + フェード 2 つのチェックに分ける (§7 の UI)。
* `to_dict` / `from_dict` は**指定があるときだけキーを書く**。
  旧プロジェクトとの差分が増えず、旧版で開いても無視されるだけで壊れない。
* `to_item()` へ `animation` / `fade_*` / `emphasis` と、
  アニメ付きのときだけ `words` (= `origin["words"]`) を載せる。

## 5. R2 `modules/subtitle_animation.py` (新規)

**ここが唯一の計算元**。出力・プレビューが同じ関数を呼ぶ (compositor・sound_mix と同じ方針)。

| 関数 | 役割 |
| --- | --- |
| `config(subtitle_cfg)` | `subtitle.animation` を既定で補完して返す |
| `split_words(entry, cfg)` | 単語列 `[{"text","offset","duration","emphasis"}, …]` を返す (§2.1 の 3 段フォールバック)。相対秒で返すため ASS でも Qt でも使える |
| `fade_tag(entry, cfg)` | `\fad(in,out)` を返す (指定が無ければ空文字) |
| `events(entry, cfg, font_profile, video_w, video_h, …)` | アニメ付きエントリを **ASS の Dialogue 本文の列**へ展開して返す。`[]` を返したら呼び出し側は従来どおり 1 行書く |
| `word_layout(entry, cfg, …)` | 単語ごとの位置・大きさ・色 (Qt プレビューと共有する中間表現) |

### 5.1 各アニメの組み立て

```
Word Pop (1 単語 = 1 イベント / 開始は語の時刻、終了はテロップの終わり)
  {\pos(wx,wy)\an5\t(0,80,\fscx130\fscy130)\t(80,200,\fscx100\fscy100)}語
  強調語はさらに \c&H…&\fs(大きめ)

Bounce (1 単語 = 4 イベント / 跳ね上がり → 落下 → 小さく跳ねる → 収まる)
  ① {\move(wx,wy, wx,wy-H, 0,  T1)}語
  ② {\move(wx,wy-H, wx,wy, 0,  T2)}語        (イベント開始を T1 ずらす)
  ③ {\move(wx,wy, wx,wy-H/3, 0,T3)} → 落下
  ④ {\pos(wx,wy)}語                          (テロップの終わりまで保持)

Big Word (1 単語 = 1 イベント / 語の時刻だけ表示)
  {\an5\pos(cx,cy)\fs(大)\fad(…)}語

Fade (種類と併用)
  既存の 1 行へ \fad(in,out) を足すだけ。コメント背景の行にも同じ \fad を足す
```

* 位置 `wx,wy` は `font_advance` の実測送り幅で求める (行ごとに左端から積む)。
  **送り幅が読めないフォントでは単語単位をあきらめ、行全体のアニメへ落とす**
  (`\pos` を使わず従来の 1 行に `\t` を掛ける)。黙って崩さず INFO を出す。
* 単語ごとのイベントは `Layer` を本文と同じにし、`\an5` (中央基準) で置く。
* `\fscx/\fscy` の既定は 100。`ScaledBorderAndShadow: yes` のため縁も一緒に拡縮する。

## 6. R3 `build_subtitle_file` への差し込み

```python
for entry in timeline:
    ...
    anim_lines = subtitle_animation.events(entry, anim_cfg, font_profile, w, h)
    if anim_lines:
        body_lines.extend(f"Dialogue: {layer},{s},{e},{style},,0,0,0,,{t}" for ...)
        continue            # 通常の 1 行は書かない (Big Word / Word Pop / Bounce)
    text = fade + text      # フェードだけなら従来の 1 行へタグを足す
```

* アニメ指定が無いエントリは**この分岐へ入らない** = 既存の ASS と完全に同一。
* 件数は INFO へ出す (既存の「テロップ個別指定 …」と同じ流儀)。

## 7. R4 画面 (インスペクタ = 本文と同じ欄)

本文・フォント・サイズ・文字寄せ・色が並ぶ `subtitle_widget` のフォームへ 3 行足す。

| 欄 | 形 | 備考 |
| --- | --- | --- |
| **アニメーション** | コンボ: `なし` / `Word Pop` / `Bounce` / `Big Word` | 選択中のテロップすべてに適用 (色と同じ流儀) |
| **フェード** | チェック 2 つ: `イン` / `アウト` | 種類と併用できる |
| **強調する語** | 1 行入力 (読点区切り) | Word Pop を選んだときだけ有効化。設定のキーワード一覧との合算になる旨を注記 |

* 注意書きを 1 行出す: コメント役割はフェードのみ / 単語の区切りが近似になる場合。
* Timeline のノードにも印を出す (ラベル末尾へ `♪` 等の記号 1 文字)。
  どのテロップに動きが付いているかを一覧で見分けられるようにする。

## 8. R5 プレビュー

* `SubtitleOverlayItem` を「単語ごとのパス」を持てる形へ広げる。
  アニメ無しのときは**今までと同じ 1 本のパス**を使う (描画コストを増やさない)。
* `set_time(sec)` を足し、`paint` で単語ごとに変形 (拡大・Y オフセット・色・不透明度) を掛ける。

* 設定 `timeline.preview.subtitle_animation` (既定 true) を false にすると、
  プレビューは「動き終わった状態」を静止表示する (B 案の退避口)。

## 10. 負荷の見積もりと保護

| アニメ | 1 テロップあたりのイベント数 | 1 時間のフルテロップ (約 1,000 本 / 1 本 8 語) |
| --- | --- | --- |
| 現状 | 1 | 1,000 行 |
| Fade | 1 | 1,000 行 |
| Word Pop / Big Word | 語数 (8) | 約 8,000 行 |
| Bounce | 語数 x (段数 + 1) = 32 | 約 32,000 行 |

* libass はこの規模を扱えるが、ASS ファイルは数 MB になる。
  `max_words_per_clip` / `max_events_per_clip` を超えたら**行単位のアニメへ落とす**
  (Word Pop → 行ごとポップ / Bounce → 行ごとバウンド)。黙って重くしない。
* 既定でアニメは**何も付かない** (`animation=""`)。全テロップへ一括適用する導線は
  今回作らない (インスペクタで選択中のものだけに効かせる)。

## 11. 互換性

* `SubtitleClip` の新キーは**指定があるときだけ**書き出す → 旧プロジェクトは差分ゼロ、
  旧版アプリで開いても未知キーは無視される。
* `subtitle.animation` セクションは `_fill_nested_defaults` で既存 setting.json へ自動補完。
* `enabled: false` で機能ごと閉じる (UI も出さない / ASS も従来どおり)。

| ② | コメント役割への Word Pop / Bounce / Big Word | 背景の箱とアイコンが追従できない (§1)。フェードのみ |

| ⑤ | 強調語の自動判定 (重要度の推定) | 根拠データが無い (§2.2) |
