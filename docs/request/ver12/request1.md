# ver12 request1 — Timeline へ SE (効果音) を配置したい

要望 (2026-11-18 / 利用者):

> Timeline 画面で、現状 SE (効果音) を載せれないようになっていると思います。
> 新機能として Timeline 上に SE を配置できるようにしたいです。
> 配置した場合は音量の調節ができるようになっていてほしい。

---

## 1. 要望の整理

| # | 求めていること | 受け入れ条件 (この状態になったら満たした) |
| --- | --- | --- |
| **A** | Timeline の任意の位置へ SE を置ける | 音声ファイル (mp3 / wav / m4a …) を Timeline へ D&D すると、落とした時刻に SE ノードが 1 つできる |
| **B** | 置いた SE の音量を変えられる | SE ノードを選ぶとインスペクタに音量 (dB) が出て、動かすと出力・プレビューの両方の音量が変わる |
| **C** | 置いた SE が出力に入る | 「決定」後に書き出した動画で、置いた位置に、指定した音量で SE が鳴る |
| **D** | 置いた SE が編集画面で確認できる | 再生・スクラブで SE が聞こえ、ノードには波形が出る |
| **E** | 置いた SE が保存される | プロジェクトを保存して開き直すと、位置・音量・ミュートがそのまま戻る |

## 2. 現状 (2026-11-18 / main)

* 音声トラック A1 のノード (`AudioClip`) は **V1 の映像クリップへのリンク**であり、
  固有の時刻を持たない (`src/timeline/model.py:430` のコメント「固有の時刻を持たない」)。
  音ズレが構造的に起きない利点がある代わりに、**単独で音だけを置く手段が無い**。
* D&D で受理する拡張子は動画と画像だけで、音声ファイルは `media_probe.is_supported` が
  弾く (`src/timeline/media_probe.py:19`)。
* 音を足す唯一の手段は「音声付き動画をオーバーレイ (V2 以降) に置く」ことで、
  映像トラックを 1 本消費し、音量も変えられない。

## 3. 付随して決めたいこと (設計で回答する)

1. 対応する音声ファイルの拡張子
2. SE 用のトラックは何本まで持てるか・最初から 1 本出しておくか
3. リップル削除 (A / D / Delete) で SE も一緒に詰めるか
4. 音量の指定方法 (右クリックの刻み / インスペクタの連続値)
5. 縦プロジェクト・DaVinci Resolve 出力へ引き継ぐか
