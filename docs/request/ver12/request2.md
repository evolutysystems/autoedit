# ver12 request2 — テロップアニメーション

要望 (2026-11-18 / 利用者):

> 次に以下のテロップアニメーションができるようにしたいです。
> 設定箇所はテロップの内容が記載されている箇所と同じ場所で設定できるようにしてください。
> 内容によっては設計上難しいとかあると思うので、そこの判断もお願いします。
> ・Word Pop（発言した単語が1つずつ大きく出現。表示時に拡大して元のサイズに戻る。重要語句は強調色に変更）
> ・Bounce（テロップが上下に跳ねる。バネのように弾んで停止。単語ごとに動きをつける）
> ・Big Word（画面中央に大きな単語を表示。1単語ずる切り替える。）
> ・Fade In
> ・Fade Out

---

## 1. 要望の整理

| # | 求めていること | 受け入れ条件 |
| --- | --- | --- |
| **A** | テロップに動きを付けられる | 下の 5 種をテロップ 1 本ごとに選べて、書き出した動画でそのとおりに動く |
| **B** | 設定場所は**テロップの本文を書く欄と同じ場所** | Timeline 編集画面のインスペクタ (本文・フォント・サイズ・文字寄せ・色が並ぶ欄) で選べる |
| **C** | 難しいものは「難しい」と判断して伝える | 設計書に可否・理由・代替案を書く (本書の設計 = `resolve2.md` §2) |

### 対象のアニメーション

| 名前 | 要望の内容 |
| --- | --- |
| **Word Pop** | 発言した単語が 1 つずつ大きく出現。表示時に拡大して元のサイズに戻る。重要語句は強調色に変更 |
| **Bounce** | テロップが上下に跳ねる。バネのように弾んで停止。単語ごとに動きをつける |
| **Big Word** | 画面中央に大きな単語を表示。1 単語ずつ切り替える |
| **Fade In** | 表示のはじめに現れる |
| **Fade Out** | 表示の終わりに消える |

## 2. 前提として確かめたこと (2026-11-18 / main)

* テロップの焼き込みは **ASS (libass)** を 1 か所で組み立てている
  (`src/modules/subtitle_generator.py` の `build_subtitle_file`)。
  出力・プレビューのプロキシ・縦動画・切り抜きはすべてここを通る。
* **単語ごとの時刻がすでに保存されている**
  (`SubtitleClip.origin["words"]` = `[{"start","end","text"}, …]` / 素材時間)。
  テロップの分割 (Ctrl+M の相方) がこれを使っている。
* 文字の送り幅をフォントから実測する仕組みがある (`src/modules/font_advance.py`)。
  行幅・コメント背景・文字寄せの箱がこれで計算されており、
  **単語ごとの表示位置も同じ仕組みで出せる**。
* 編集画面のプレビューは Qt の自前描画 (`SubtitleOverlayItem`) で、
  **停止中・再生中とも「時刻では描き直さない」**作りになっている
  (ver8 resolve8 §9-3 / ver9 resolve7 の軽量化)。ここが今回の論点。

→ 可否の判断と設計: `docs/request/ver12/resolve2.md`
