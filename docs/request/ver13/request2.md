## 要望

ver13 request1 のチェックボックスを入れたあと、無音カットを外してセクションを追加したが
「まだ無音カットされている」という報告があった。ログを解析した結果、**チェックボックスは
正しく効いており**、見えていたのは別の 2 件だった。

| # | 件名 | 内容 |
|---|---|---|
| A | 範囲が連続に戻らない | 無音カットを外して追加しても、**指定範囲のうち既に Timeline に載っている部分は手つかず**のため、聴くと切れたまま |
| C | 切り出し原点のずれ | 要求 1.4 秒に対し素材が 3.08 秒。`-c copy` の切り出しが要求位置より手前 (最大 1 GOP) から始まり、**ラベルと中身が約 1.7 秒ずれる** |

B (10 秒以下の穴を拾えない / `used_gap_merge_sec`) は A の実装で解消するため、独立の対応は行わない。
