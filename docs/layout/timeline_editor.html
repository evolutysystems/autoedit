構造は縦分割 (上 55% : 下 45%) の中に横分割 (プレビュー 4 : インスペクタ 1) が入る二重の QSplitter。比率は setting.json timeline.ui.split_ratio。
  • トラックの並び順は timeline_view.build_rows のとおり 上から 字幕 → 追加映像 → ベース映像 → 音声。
  • クリップ・再生ヘッド・選択枠はガラス化の対象外で、編集点の判別精度を保つため不透明色のまま (R10)。
  • Timeline の背景 (下地) だけが半透明で、ウィンドウ背景のグラデーションが透ける。ライト時も常にダーク基調。
  • アーカイブ用 (archive_timeline_dialog.py) は同じ画面を QMainWindow で包み、 上部へ採点グラフのドックを足したもの。決定ボタンの文言は「完了（切り抜き＋字幕焼き込み）」。
