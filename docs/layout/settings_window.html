全タブが「項目名ラベル (最小 100px) + 入力欄 (最小 160px)」の 2 列グリッド (QGridLayout / 横 12px・縦 8px 間隔)。実装上の最小幅 300px はこの 2 列の合計で決まる。
  • 役割別カラー (テロップ / アウトライン) だけは横 1 行へ 3 列並べ、各列を「役割名 + 入力欄 + 色見本」の縦積みにする (resolve4 S2 / S3)。
  • アーカイブタブのみ見出し (#sectionTitle) と注記をグリッドの外へ置き、節の順序を保っている。
  • 先頭タブ (一般) 選択中だけペイン左上の角丸が外れる (theme.bind_tab_pane_corner)。
