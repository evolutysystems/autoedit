Stretheus 画面レイアウト (HTML / CSS 版)

PySide6 で実装された 3 画面のデザイン・レイアウトを HTML/CSS へ置き換えたもの。
色・角丸・余白は src/gui/theme.py のデザイントークンと QSS、 寸法は src/settings/setting.json の実値をそのまま使っている。 実装の変更ではなく、デザイン確認・共有のための資料。

1. メイン画面 (最初の実行画面)

「クリップ用 / アーカイブ切り抜き用」の 2 タブ。入力動画の指定、実行ボタン、 編集の続き、進捗バー、ステータス。設定ボタンはタブ外の右上コーナー。

src/gui/main_window.py / archive_tab.py / project_resume_row.py

2. Timeline 編集画面

プレビュー + インスペクタ + Timeline の二重分割。ルーラ、トラックヘッダ、 クリップ、再生ヘッド、ズーム操作、下部ボタン行。

src/gui/timeline/timeline_editor_dialog.py / preview_panel.py / timeline_view.py

3. 設定画面

「一般 / 字幕 / 縦動画 / アーカイブ」の 4 タブ。項目名 + 入力欄の 2 列グリッドと、 全タブ共通でタブ外に置かれる保存ボタン。

src/settings/settings_window.py
